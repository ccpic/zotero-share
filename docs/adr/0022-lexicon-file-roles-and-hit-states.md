# ADR-0022 词表三件套分工：协议出数据桶、镜像与变更记退场、候选缓冲为任务队列、命中判据拆分

- 日期：2026-09-18；状态：已接受；来源：grill-with-docs 会话（三轮 13 问 live exchange）——用户拍板协议落点、删变更记、删镜像、缓冲出账、判据拆分、字段面、门禁契约、历史留痕与 ADR 形式。
- 背景：`references/lexicon/` 三件分工不清，md 一件混装四种角色——协议（§1–3、§5–7）、机器生成镜像（§4 受管区块）、机器追加＋手写变更记（§8）、手写版本行。漂移是结构性的：`apply_promotion()` 只重写受管区块与插入 §8 行，不写版本行，实测 md 写 v3.0 而真源与 §8 已是 v4.0；md 自己声明「版本号必须与 YAML 一致」，兜底却是手工仪式（「两处不一致以 YAML 为准，并在下一轮生长循环里记一条问题」）。版本／历史并存三处（真源 `version`+`frozen_at`｜md §8｜缓冲 `status`/`promoted_to`/`lexicon_version_at_record`）；缓冲的 `proposer`/`recorded_at`/`updated_at`/`lexicon_version_at_record`/`promoted_to` 只写不读（读面只有 `term`/`family`/`edges`/`source`/`status`/`version_candidate`）。`--log` 对「未命中」与「命中但无边」同报「扩展 0 个」，门禁同判——已晋升无边术语（高血压／ARNI／CCB 等 `relations: []`）在后续任务中永远要求缓冲条目，缓冲只增不减（23 条：13 已晋升＋10 待晋升）。md 无任何机器读者与一致性断言。
- 决定：
  - **协议出数据桶**：md 的协议部分（四分语义、字段与落点、消费节点、命令清单、T-01 口径、生长循环）迁 `references/protocols/term-lexicon-protocol.md`；`references/lexicon/` 只留数据件（真源＋候选队列）。ADR-0017 拒拆的理由是「镜像与真源配对」，镜像退场后该理由消失；K-01 门禁（三桶俱在）不受影响。
  - **镜像退场**：删 §4 人读镜像；按需读表走 `term_expand.py --dump [家族]`（复用原渲染函数）。手写叙述注分流：可复用判据（疾病族取中文主名／药物族取英文 INN、未确证译名留空不猜补）收进协议件，建族过程与纠偏留痕只归 git。
  - **变更记退场**：删 §8；历史归 git（真源 `version`/`frozen_at` 与每术语 `source` 字段已记来源与拍板原话）。
  - **候选缓冲＝任务队列**：字段面收为 `term`／`family`／`edges`／`source`／`version_candidate`；**文件即队列**（在队＝待晋升），晋升一次成型写真源＋bump 版本＋出账（被晋升条目移出）；`--append` 幂等合并不变；CLI 去 `--proposer`/`--md`。旧格式条目一次性清理（13 条已在真源者出账）。
  - **判据拆分**：查询词三态 `expanded`／`hit_no_expansion`（命中无边：已收录、无可扩展边）／`miss`（未命中：未收录）；`--format json` 增 `status`（机器契约），`--log` 人读行同步；门禁判红＝「声明为未命中／候选，但既不在真源也不在队列」；`covered` 占位取消。
  - **强制守卫（非选择项）**：晋升遇条目已在真源→跳过并出账＋告警，不空跑版本号（否则是无变更的静默 bump）。
- 备选（未采纳）：协议留 lexicon 桶（协议与数据混桶）｜协议拆两件（消费与晋升常同读，多一次跳转）｜保留镜像并加一致性断言（多一条断言面，收益薄）｜变更记迁 YAML `history` 段（与术语 `source` 重复）｜缓冲并入真源（破坏「任务内真源冻结 vs 队列可写」的写路径分离，且队列写会改真源 `sha256`、冲掉解析缓存键）｜缓冲移出 skill 包（跨任务队列语义与门禁路径都要改）｜缓冲保持永久账本（无边术语判据不拆时只得永久保留或反复重录）｜门禁解析 `--log` 文本标记（文本耦合脆）｜门禁自读真源判成员（解析逻辑两处实现）。
- 后果：改写 `scripts/term_expand.py`（`status`、`--dump`、晋升出账与跳过守卫、去 `--md`/`--proposer`/`covered`/镜像重写/变更记）、`scripts/check_growth_loop.py`（判据改读 `status`）、`evals/acceptance/run_gate.py`（A-08 判据文本与生长循环孪生节文案）、`SKILL.md`（可追溯契约、校验章、references 索引）、`references/protocols/review-rules.md`（T-01 复述改一句话指针）、`references/templates/screening-log-template.md`（落盘口径改「未命中才落队」）、`evals/evals.json`（文件清单换协议件路径）、`CONTEXT.md`（候选缓冲重定义、晋升补出账、新增「命中无边」）；删 `references/lexicon/term-lexicon.md`；缓冲清旧格式（13 条出账、10 条改新字段面）。`anchors.json`／`A-09` 等按真源 `version:` 行的读取方不受影响。
- 修订（2026-09-18，边入口与机械生长红线）：`--append` 增边入口 `--edge "type:target:方向"`（可重复）与 `--canonical`／`--no-edge`；候选字段面扩为 term／family／canonical／english／edges／source／version_candidate／no_edge；晋升分「新增」与「并入」（并入＝新边并进已有术语块，原字段与 source 保留、晋升来源追加），只有**无增量**的陈旧条目才出账；交付门禁增「本交付触达的家族 ≥2 条术语且全体无边、又未逐条 no_edge → 机械生长，判红」；删除 `term_expand.py` 与 `review_knowledge.py` 里的内置关系副本（无表＝不扩展、不猜关系；`--fallback` 改为无表姿态演练）；新增机制自检 `check_growth_loop.py --selftest`（沙箱回归：边入口 → 晋升出账 → 扩展 → 无边与主名落真源）。**同日用户纠正**：商品名与开发代号是别名、不是同义形——沙库巴曲缬沙坦条的 Entresto／诺欣妥／LCZ696 已由同义边改记 `abbreviations`／`chinese_aliases`（同义集随之删除），规则写进协议件命名惯例；该纠正恢复了与 ruxolitinib 条（Jakafi／Jakavi／Opzelura 记缩写）一致的既有惯例。**同轮补强（生成侧自然生长）**：① `--append` 输出加「生成侧 nudge」——回声本族现有术语（真源∪队列、带边／无边标态）并提示记边或 `--no-edge`；② 机械生长红线由「家族 ≥2 且全体无边」改**逐条口径**（本交付声明且已落库的术语，无边又未声明 `no_edge` 即红），补上「新族只登记一个词」的静默漏洞；③ `--no-edge` 明确可作 AFK 下的**提案**，由晋升计划表（标「待你确认」）带表确认；④ SKILL.md 常驻面把四类名与问法指针写进 Step1 格（resident surface 自足）。背景：`--append` 原先只能镜像真源已有边，未命中词恒为无边——2026-09-18-arni-ccb-hypertension 交付因此只登记 5 个无边术语、零同义／上下位边（ADR-0016 的「声明即须落盘」被满足，词却仍是机械生长；同时暴露 LDL-C 票的血脂／降脂药物两族同形）。
