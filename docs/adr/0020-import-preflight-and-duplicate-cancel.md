# ADR-0020 入库预检：DOI 权威快速查重与重复取消

- 日期：2026-09-18；状态：已接受；来源：grill-with-docs 会话（四轮 17 问 live exchange）——用户拍板重复定义、取消粒度、范围、信号、顺序与短路、索引阈值与持久、失效语义、词条命名与缺口分流。
- 上下文：添加文献（含全文链）此前先取 Crossref 元数据**再**查重，去重路径 4 次检索≈8.8s/篇（实测：本机 666 条条目、本地 API 单次检索≈2.1s、children 查询≈2.1s）；重复篇白付网络与检索代价。用户目标句：「添加文献时最快速度发现是否重复，重复则尽快结束动作，取消导入」。
- 决定：
  - **DOI 权威预检先行**：以归一 DOI（大小写/前缀无关）为权威键，在取元数据与写库之前做入库预检；命中零网络元数据；未命中才取 Crossref。
  - **单探针预检**：整串探针 1 次检索（≈2.2s）；后缀/标题探针降级为未命中后的慢路径补充，且慢路径命中即停（后缀命中→不跑标题）。
  - **重复取消＝单篇终止**：命中正式条目且无正文附件缺口 → 该篇立即终止（不取元数据、不写库），批量内其余篇继续；快照/无 DOI 命中不触发取消。
  - **命中带缺口转挂载**：命中但缺正文附件（正文附件缺口）→ 不取消，转挂载链补挂。
  - **三态输出**：`DUP`（取消）／`DUP-GAP`（转挂载）／`NEW`（未命中）；exit 0；`SKIP` 保留旧语义（已有条目、本轮免建）。
  - **批量混合路径**：≥10 篇先建进程内全库 DOI 索引（一次≈21s，含库版本探针验鲜）后逐篇 O(1) 查询；阈值以下逐条探针；索引不跨运行缓存。
  - **fail-closed**：预检异常一律中止报错，不得当未命中继续建库。
  - **挂载点**：独立预检脚本，编排层在研读选取集（＝下载队列＝入库集，队列口径沿 ADR-0032）生成前排跑（下载前位置）；scansci 零改动。
- 备选（未采纳）：**维持先元数据再查重**（重复篇白付 Crossref）｜**标题关键词为主**（排序/limit 截断漏命中，实测）｜**预检双探针**（≈4.4s，破探针预算）｜**跨运行索引缓存**（陈旧＝漏判重复的风险面）｜**命中缺件也照常取消**（用户改选转挂载链）｜**整批中止或可配置粒度**（批量导入必然中断）｜**专用退出码**（破既有 0/1 约定）｜**预检失败降级继续**（重复条目风险）。
- 后果：
  - 性能契约双段：重复存在性探测≤3s；含正文附件核的完整取消判定≤5s（A6 引入的 children 调用≈2.1s 为必然代价）。
  - 词表：`CONTEXT.md` 新设「入库预检」区——「入库预检」「重复取消」「正文附件缺口」三词；「跳过」维持旧语义。
  - 职责互补：入库预检治「是否要动」（命中即分流），「补漏环」治「缺件补救」（独立补救轮仍走原链路）。
  - 文档联动（实现时执行）：`use-zotero`（`references/local-api.md` 去重规则改写为预检口径；预检脚本及其契约落 `scripts/`；`seed_from_doi.py` 顺序改为 DOI 预检先行并产 `DUP` 行）；全文链（`placement.md` 与编排规程）写入下载前预检的排跑位置。
- 交叉引用：与 ADR-0007（附件挂载契约）交界——缺口转挂载沿用其挂载与身份核验规则；ADR-0002（批量链路确认优先）不受影响——预检在确认门之前剔除重复篇；**ADR-0032**（队列即研读选取集：预检范围随之由「下载队列」读作「研读选取集」）。
