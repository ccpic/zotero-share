# ADR-0035 §5 装配链收进 skill：共享草稿脚本＋W-24 硬门＋引文表单源

- 日期：2026-09-23；状态：已接受；来源：grill-with-docs 会话（Batch 三轮＋追加 P1–P6 六问）——用户拍板：只收两条引用链＋§5.1 名单组序（D1/D1a）、§5←引文表（D2）、著者冻结（D3）、删旧包脚本（D4/D4a/D10）、草稿形态（D5/D7/D9）、crossref 输入（D6）、模板一句话（D8）。
- 上下文：2026-09-22 交付的证据表「文献」列被交付内临时脚本拼成「作者，年，期刊，DOI」，题名整段丢失；渲染器对该形态静默退化（整格塞进主行、副行不渲染），门禁无一条判该列，一路绿灯交付。根因不是渲染器忘写题名——是「卡→§5 行」投影没有 skill 侧共享实现，每份交付由 `run/scripts/` 临时脚本现场生成（忽略位、不进版、不在再生清单），换一份交付换个脚本，形态一改旧病复活。旧包里只有 `step5_table.py`（teriparatide）是正确的投影实现（六列从卡投影、文献列按标识段位序自拼 GB/T），其余各写各的。
- 决定：
  - **三共享草稿脚本**（`.claude/skills/med-lit-review/scripts/`，只写 `run/` 草稿件、不碰包内真源；D5/D7）：`step5_reference_list.py`（引文表草稿，吃 `run/step5-crossref.json`＋可选 enrich 补缺；D6）、`step5_table.py`（七列表草稿，「文献」列取引文表同号条目全文去尾点）、`step5_priority.py`（§5.1 名单与组序草稿，理由与维度人工填）。调用链写进 `SKILL.md` Step5 格。
  - **引文表单源**（D2）：「文献」列唯一取数来源是 `agent/reference-list.md` 同号条目；引文表缺行号、卡题名/首著者姓交叉核对不符、未知元数据类型，即退出 2（不猜补）。模板一句话同步（D8，`reference-list-template.md` §5）。
  - **硬门禁 W-24**（`check_delivery.py`＋`review-rules.md` §6）：§5 逐行按渲染器同一函数判「拆档成功（年份·期刊位）＋主行带 GB/T 类型标识＋主行去标识后仍有可见实体（题名位）」；配两孪生变异（自拼简式／只剩作者串）。
  - **著者格式冻结**（D3）：引文表全名式、§5 首字母式并存；W-24 只判题名在场，不碰著者，旧包零迁移（W-24 在 52/38/34 行三份旧包全过）。
  - **旧脚本删除**（D4/D4a/D10）：删 09-19／09-21／ldl 三份旧包的 `step5_table.py`／`step5_reference_list.py`／`make_reference_list.py`；09-19 manifest 的 `step5_assets` 再生引用留字（已封存包历史账不动）。本交付刚修好的 `build_evidence_table.py` 改草稿形态保留作过渡，共享脚本落地后删。
- 备选（未采纳）：
  - **§5→引文表**（D2 反向）：著者格式会被 §5 首字母式污染，引文表失去 canonical 意义。
  - **整串含纳式硬门**（§5 文献列必须含引文表条目全文）：teriparatide 全名/首字母两制式下 0/38 通过，走不通。
  - **机器定先读名次**（模板③硬约束化）：实测把 {1,7,19,32} 拆散，与人工定稿不一致；③ 留作人工自由裁量（P3）。
  - **S 序作第⑥轮**（P6）：S 序 268（行15）vs 499（行25）倒排无口径依据；差异如实交付，不伪造一致。
  - **草稿直写包内真源**：与 R4 生成后自查冲突，且门禁读的正是该真源，机器直写等于自证闭环。
- 后果：新增共享脚本三件＋W-24 一门；旧包 `run/` 脚本删四件；`SKILL.md` Step5 格、两模板一句话、`reader-html.md` 义务 4 落字。`CONTEXT.md` 新增「证据表草稿」通用词（本条只记决策，术语见该词条）。被引口径收敛到 `cited-counts.json` 快照（P2：enrich 碰撞串行不得作回退）。§6.2 散文超长单行（1368 字节）已暴露 L-03 整段豁免风险，修法（软换行何处落）不在本条，另开议题。
