# ADR-0014 med-lit-review 触发收窄：交付物＋医学域双条件

- 日期：2026-09-17；状态：已接受；来源：grill-with-docs 会话（三轮 7 问 live exchange，用户逐项拍板）。
- 上下文：`med-lit-review` 的 SKILL description 原含「疾病知识与机制盘点」，导致找文献前的单事实／概念背景调查也被路由进重型五步链（入口两问＋检索下载入库研读），与用户期望的「背景直接回答」冲突。同时原描述无域约束，其他行业论文也可能误触发。
- 决定：触发条件收窄为交付物＋医学域双条件：
  - 交付物条件（二选一）：① 用户明确要医学文献／循证交付物（八节包／七列表／分级／分级入库／已有文献写总结）；② 给定具体医学主题并要综合证据（topic＋综合意图双条件，单给 topic 不算）。
  - 医学域条件（必备）：属人用药／疾病／临床证据／指南共识／监管文件范畴；其他行业论文不触发。
  - 删除「疾病知识与机制盘点」触发语（确认为误触发源）。
  - 单事实／概念问答直接回答、不触发；「系统看一下／全面了解」类模糊请求默认直接回答＋末尾反问是否出系统包，要才进 skill。
- 备选（未采纳）：关键词即触发（过宽，打回原形）；研究问题／路线点名才触发（过严，正常综合请求无 PICO 也该进）；分级入库才算（把纯检索综合排除在外，与 P1 形态冲突）；背景走 jadense 直检或 P1 摸底（用户拍板直接回答更轻）。
- 后果：仅改 `SKILL.md` description 触发句＋本 ADR；CONTEXT.md 不动（无新通用词）；不补 trigger 反例（D5.1 已定）。模糊请求的「直接回答＋反问」为执行口径，不进 HITL 协议（入口问只在进 skill 后才弹）。
