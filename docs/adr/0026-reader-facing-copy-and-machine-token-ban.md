# ADR-0026 读者面文案层：人读主件的机器记号禁令与读者词表

- 日期：2026-09-20；状态：已接受；来源：人读主件读者面文案清理（grilling 会话：先把「哪些词不适合人读」逐项定案，再落执行体）。
- 上下文：人读主件是**外发面向人的单页**（单文件自足、断网可开），但它渲染的正文、说明句与页尾横幅此前夹带生成器与流水线的机器记号——正文引用写 `行 N`、说明句写 `#row-N`／`#card-<DOI-slug>`／`1..N` 一类占位符、缺失读数记 `∅`、正文直出 `agent/…`／`run/…` 路径与可粘贴的 `uv run` 命令、卡片抽屉里 `## 小节` 与无名段被并进上一条正文（页内 77 处 `##` 泄漏、整句被当成段名、同句重复出现）。同一份文案同时服务两类读者，导致机器面需要的记号直接污染了人读面。
- 决定：
  1. **读者面词表落在渲染层**（唯一家＝`reader_html.py` 的 `ROW_LABEL`／`MISSING`／`ROUTE_WORDS`／`CALIBER_WORDS`／`FILE_LABELS`）：证据表一行记「证据行 N」（正文、行标、排序项、卡内返回链接同词）、缺失读数记「未取到」、路线与口径码写「完整路线（P0）」「灰色渠道默认启用（post-0006-fastest）」这样的**通俗词＋括注身份码**。
  2. **契约记号不动、只增读者词**：markdown 真源与 §5.1 表沿用 `行 N`（消费者一律子串匹配，`证据行 N` 天然兼容）；W-06 的括号预算正则放宽；`package_parse` 的行列名同时认「行」「证据行」。
  3. **页尾＝复核入口区**：页内**唯一**允许出现仓库路径与可粘贴命令的区域，列交付件（正文点名件＋关键四件，逐条「件名 · 路径」）与复核命令（三件套＋页面复算，按在场件裁剪，引文面降级时附重跑命令），并保留输入件指纹；正文里的件路径换成指向该区的件名链接，降级块不再直出命令。
  4. **读者面零机器记号**：锚点记号（`#row-`／`#card-`）、尖括号占位符、占位符 N（`行 N`／`1..N`）、`∅`、内部件路径、脚本或数据件名、`uv run` 命令、未渲染 markdown（反引号与 `## ` 标题）一律不得出现在读者可见文本。
  5. **判定进硬门禁**：新增 `W-21`（剥样式／脚本与页尾复核区后扫描读者可见文本），并在 `--selftest` 增孪生变异场景（注入占位符与锚点记号即判未通过）——契约类断言进硬门禁依据 ADR-0025 决定 10 的收窄口径（结构／封顶类仍停软项）。
  6. **卡片抽屉按真源结构渲染**：`## 小节` 与其成员整体折叠（折叠标题列小节名与段名），无名段不显示段名，标题后首个字段前的散段不丢。
  7. **分级记号保留＋页内一次图例**：E1–E5／先验／升降档／可及性三值照用（它们是筛选与表列的身份词），只在证据表说明句给一次通俗解释；`CONTEXT.md` 通用词（终池、摄入过滤、被引下限等）一字不改。
  8. **本交付包同步改真源**：指针形态改名（`行 N`→`证据行 N`，只动指针：括号引用、行号链、§5.1 列头与其单元格、结论块行号字段）、八节与子节标题补 `§`、机器记号改读者说法，并重生成页面、重登记 `versioned_artifacts[]`／`derived.reader_html` 与门禁摘要读数。
- 被取代的旧条款与同步面（做法家就地改写）：`reader-html.md` §3 增渲染义务 13（读者面文案）、改写义务 1／4／5／7／11；`review-rules.md` §6 增 `W-21` 行、`W-06` 出处措辞改「证据行 N」；`evidence-table-template.md`（列头「证据行」、§5.1 表头与样本、指针写法）与 `conclusion-template.md`（`｜<证据行>`）；`SKILL.md` 增「读者面文案」口径条并在硬门禁枚举里带上 W-21；`review_knowledge.py` 的节号识别容忍 `§` 前缀并把「§6 先于 §5」的设计序写成容错（原为三处 F-04 告警，实为设计序）。
- 备选（未采纳，均带理由）：**只清渲染器自造串、真源照旧**（页内仍会直出真源路径与 `R1／success／1-hop` 一类流水词，人读面照旧破功）｜**读者面统一通俗化**（终池→纳入池一类会与 `CONTEXT.md` 的 `_Avoid_` 纪律冲突，输出词表必须单一）｜**机器记号留在正文＋页内加解释**（外发件仍要求读者懂仓库结构）｜**复核命令留在正文降级块**（路径与命令进正文即破 W-21，且降级块本无命令语义）｜**把整段 §3／§7 从页内摘除**（方法与局限是人读件的一部分，摘除＝少内容）｜**不给门禁断言、只靠评审**（渲染器下次改动即回归，属典型可断言事实）。
- 后果：人读主件读者面**零占位符、零锚点记号、零内部路径与命令**（页尾复核区除外），路径与命令仍可复查且集中在固定区域；同一份页面对外可发、对内可核。代价与已知：① 机器面词（`行 N`）与人读面词（`证据行 N`）分家，靠渲染层映射与 W-21 守——作者写 `行 N` 不再等于页内写 `行 N`；② 页尾件清单随正文点名件变化，故件清单不是定值；③ 体积软项仍超封顶（W-17 记读数不阻断，成因是 60 张卡的 verbatim 密度）；④ 冻结的历史包仍按旧文案渲染，不复算、不追改。
- 交叉引用：ADR-0025（人读主件是派生渲染件、`machine_reads: false`、契约类可进硬门禁）、ADR-0009（词/做法/决策三分工：本记录只记决策，词表与义务在 `reader-html.md`，词条在 `CONTEXT.md`）、ADR-0010（交付根固定四项与进版件哈希）、ADR-0023（可及性三值与摘要级义务）。
