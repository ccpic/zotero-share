# ADR-0025 交付产出分层：人读主件、机读归档与渲染契约

- 日期：2026-09-19；状态：已接受；来源：`.scratch/workspace-output/` 路线图冻结票（01 耦合面盘点、02 HTML 信息架构、03 关系图设计、04 落点与索引、05 渲染脚本规格、06 门禁与校验面、07 精读序口径、08 规范与 ADR 落字）及其执行票（该目录 `issues/`，本记录由其中的 06 号票落字）；逐文件落字清单见该目录 `assets/08-spec-and-adr-landing.md` §2，PRD 与地图见同目录 `PRD.md`／`map.md`。
- 上下文：`med-lit-review` 的交付产出此前没有「给人读」与「给机器读」的分层——真源、账目件、索引、派生件与生成脚本全平铺在 topic 顶层（LDL-C 包顶层 16 条目、arni 包 15 条目），两处字节全同的重复对（`doi-list.txt` ≡ `download-queue.txt`、`extraction-cards.md` ≡ `extraction-cards.merged.md`）使「哪件是唯一真源」不可判；唯一人读入口是双层 `INDEX.md`（既导航又查询），读者判断「先读哪些文献」只能自己在证据表与几十张单卡之间来回翻。同一形态把三处矛盾带进机器面：①门禁按 `^##\s+提取卡` 切合卡，而合卡规范是「源件原样拼接」，实包因此解析到 **0 张卡且静默通过**（另一包直接 `FileNotFoundError`）；②`R3` 与合卡条目称合卡「机器禁读」，而门禁正是机器读它；③生成脚本按 `download-queue.txt` 走、门禁却按 `doi-list.txt` 读，队列与身份列表在同一路径上读写倒挂。门禁对 `INDEX.md`／`gate-summary.md`／`cards/` 的覆盖为零。旧封顶（顶层 ≤12 条目、版内 ≤~35 文件）的基准本身已失真——四个真实包全部越界（LDL 16／42、arni 15／41、jakib 14／24、myelo 14／29）。
- 决定（本记录只承载决策、阈值与分界；逐条执行形态、渲染细则与门清单各以真源为准，不在本记录二次展开）：
  1. **分层判据与落点**：判据＝叙事 vs 契约／账目——叙事件（结论、证据表、引文、关系图、精读序、入口）人读；契约与账目件（八节包、单卡、检索策略、筛选日志、下载台账、落点计划、引文表、监管补充、门禁摘要、再生清单、身份列表、队列、监管版本记录、商业库导出原文）机读。交付根**固定**为 `INDEX.md`／`<slug>.html`／`agent/`／`run/`；真源与账目件进 `agent/` 直下扁平（`cards/` 为唯一子目录）；`run/` 位次与忽略语义不动（`.gitignore` 三级顺序语义零改动）。粒度规则按此改写并保编号：`R1` 改索引单层、`R3` 改卡片单形态、`R6` 改枚举制，`R2` 补「人读主件是派生渲染、非第二处真源」，`R4`／`R5`／`R7`／`R8` 保留（规范 `references/protocols/workspace-guide.md` §6／§8）。
  2. **根 `INDEX.md` 改机读纯索引（单层）**：文件表（一行一件）＋寻址命令表（任务→可粘贴命令，仓库根相对）＋**唯一一行**状态计数＋「待查」纪律；明禁抄结论、写 verdict／建议／优先级／因果，及除该行外的任何读数；人读导航不再进索引，由人读主件承担。骨架可机器判（门禁 W-09）。
  3. **人读主件与渲染契约**：交付根 `<slug>.html`（`<slug>`＝`manifest.topic.slug`，不含日期与 `-rN`），单页全包（八节＋七列证据表＋关系图＋提取卡＋精读序），由版内 markdown 真源**确定性渲染**（执行体 `scripts/reader_html.py`）。契约唯一家＝`references/protocols/reader-html.md`（CLI 与退出码、输入分档、渲染义务、确定性口径、`manifest` 登记、调用位次、失败分档）。要点：输入件字节不变 ⇒ 重跑逐字节相同（`--check` 为执行体，页脚记输入指纹）；单文件自足、断网 `file://` 可开；调用位次＝Step5 之后、交付门禁之前（横切一步，不占 Step 号，ADR-0016 先例）；程序级失败（必需件缺／卡面 0 张／行号两处条数不一致／两条目皆无）退出 2 并阻断交付，数据级缺件降级产页（图位恒在）；演示件不产人读主件——渲染与确定性口径的演练面由 `--check` 承担（规范 §13）。
  4. **合卡退场**：`extraction-cards.md`／`extraction-cards.merged.md` 不再产（派生件唯一实例随其退场，规范 §12「派生标记惯例」整节退场）；单卡 `agent/cards/<DOI-slug>.md` 为唯一家（一件一篇、文件名即身份即寻址）。门禁卡面解析改读该目录：解析到 0 张或目录缺**显式报错**（报读取路径与解析条数）——治「按单卡语法切合卡得 0 张且静默通过」的失效模式。
  5. **封顶枚举制（`R6`）**：顶层固定四项（出现第五项即结构错误）；`agent/` 直下 ≤14 条目（P0 基准 12＝11 件＋`cards/`）；`agent/cards/` 逐卡不计入；体积 ≤2.5MB；`step1-pools` 一类原始池不计。依据：旧「顶层 ≤12／版内 ≤~35」在四个真实包全部越界，旧基准（~1.7MB／31 件）已失真；新阈值下各包均在界内，体积余量约 55%（LDL 新形态估 1.5–1.7MB）。
  6. **双契约分离（身份列表 vs 队列）**：`agent/doi-list.txt`＝**身份列表**（终池去重后全量 DOI，含未进队列者）；`agent/download-queue.txt`＝**研读选取集**（＝下载队列＝入库集，成员一次选定、三处同用，沿 ADR-0032；Step2 选取步产出、一行一条、Step3 的输入，台账行数＝本件条目数）。两件都留、各有消费者；剪队列不改写身份列表。依据：两件只在队列未被裁剪时字节全同（LDL／arni 全同，myelofibrosis 242 vs 28 行、ruxolitinib 145 vs 30 行）——「重复」是假象；同时纠正脚本按队列读、门禁按身份列表读的倒挂（门禁改读 `download-queue.txt`）。
  7. **`derived` 段语义（派生渲染件）**：`manifest.json` 的 `derived` 段保留、唯一成员换 `reader_html{path, sha256, inputs[{path, sha256}], command, machine_reads: false}`——段语义由「派生合卡」改「派生渲染件」；`machine_reads: false` 记「机器读面在 `agent/`，渲染件不是第二处真源」。`versioned_artifacts[]` 与 `ledger_pointers{}` 的值带 `agent/` 前缀（根件不带）；`regeneration[]` **不增** HTML 项（该段语义＝`run/` 被忽略件，路径仍 `run/…`）。
  8. **擦除演练分流**：删 `run/` 内容 → 按 `regeneration` 逐条重建 → 逐件哈希对账；人读主件按**输入哈希**分流——`derived.reader_html.inputs[]` 全等时以 `--check` 复算比对（记 `MATCH`），任一漂移（`run/` 依赖网络重取、不承诺跨跑字节复原）记「输入漂移、跳过」，**不判失败**。
  9. **必跑三件套与交付形态检查面**：交付必跑由两件改**三件套**——`scripts/review_knowledge.py`（对象是八节包）＋`scripts/check_growth_loop.py`（读 `agent/screening-log.md`）＋新 `scripts/check_delivery.py`（交付形态契约）；任一缺口即阻断交付（同 ADR-0016 的阻断语义）。卡面／包解析抽共享模块 `scripts/package_parse.py`（一份解析两处消费，禁第二份）。W 组检查面：硬门禁 W-01..W-05／W-07..W-12 在 `check_delivery.py`（主件在场与命名／自足／锚点完整／DOI 可定位／卡全覆盖／图契约／渲染对账／索引骨架／摘要骨架／落点一致／卡面解析健康），W-13 版内件机密面在 `evals/acceptance/run_gate.py` 的 `secret_scan`（纳入 `.html`，扫描前剥离样式／脚本块、内联数据 URI 与 CSS `url(...)`），W-06 精读序三条（存在性／出处／域封闭）读 markdown 真源、归研读侧口径；W-14..W-19 结构／封顶类只出读数并告警。交付期**漂移抽跑** `--card-probe`：用门禁自己的解析器跑最新**同形态**真实包、只判解析器健康（条数＝`agent/cards/*.md` 件数、0 卡即红），无可抽样本记「样本缺位」（不报错、不阻断）。档位映射与及格线的唯一真源＝`references/protocols/review-rules.md` §6。
  10. **结构断言红线收窄**：ADR-0010「驱动分层」的「不新增 workspace 结构断言」收窄为「**结构／封顶类停软项读数、内容／契约类可进交付门禁**」——W-01／W-09／W-10／W-11 等契约类硬项成立，顶层四项／`agent/` 件数／体积等结构类停在软项读数，提档须再议。`K-01`（`references/` 分桶不变式）不受影响。
  11. **历史包冻结与形态分界**：产于分层之前的交付包**完全冻结**——内容一律不动（含合卡两件与 `doi-list.txt` ≡ `download-queue.txt` 一类旧重复对），不逐包加注记、不破包内 `manifest.json` 的哈希记录；判别特征与读法写进规范 `references/protocols/workspace-guide.md` §16「历史包读法」；历史包在新门禁下的未过读数按 ADR-0008 留档、不作交付阻断。
- 被取代的旧条款（互指 `docs/adr/0010-workspace-persistence-contract.md` 末条窄修订条）：「单源与派生」的合卡句（合卡作派生件、`derived from …` 头部标记、执行体与机器禁读）由决定 4／7 取代；「三件合约」的 `INDEX.md` 单件双层句（人读地图在前、agent 查询式在后）由决定 2 取代（`manifest`／`gate-summary` 两件的分工保留，见规范 §10／§11）；「边界与忽略语义」的进版枚举（含合卡、`cards/` 与 `b2/version-record.json` 无前缀等）由决定 1／6 取代（新枚举＝规范 §6）；「版内封顶」句（版内 ≤~35 文件、约一到二兆、顶层 ≤12 条目）由决定 5 取代。
- 备选（未采纳，均带实测或结构性理由）：**`INDEX.md` 保留双层**（人读导航与机器索引两种读者混在一件，正是本次要拆的耦合；人读层改由 HTML 承担）｜**保留合卡**或改「合卡＝唯一机器读面」（同内容两处必然漂移；门禁已实测按合卡解析得 0 张卡）｜**落点保持平铺**（只加 HTML 不搬 `agent/`：顶层件数与「哪件是唯一真源」仍不可判）｜**人读 HTML 作第二处真源**（手写或事后编辑，与 `R2` 单源冲突；渲染件只作派生渲染）｜**关系图运行时力导向布局**（不可复现，与「同输入同字节」承诺冲突；改预计算确定性坐标）｜**结构／封顶类提为硬门禁**（大包被判死，与「大包该提示而非阻断」的目的相反）｜**历史包迁移改写或逐包加形态注记**（破坏包内 `manifest` 哈希与版本身份；旧可读性由判别特征保证）｜**跨 topic 全局索引**（重申 ADR-0010 禁令，`ls workspace/` 即全局视图）。
- 后果：交付形状固定——真实包顶层由 16／15 条目降到 4，两处字节全同的重复对在新形态下自然消失（身份列表是全量、队列是裁后集）；人读入口由「双层 INDEX ＋ 39 行表 ＋ 数十张单卡」改为单页 HTML（同输入同字节、`--check` 可复算、页脚输入指纹）；机器面寻址稳定（basename 一律不改、只换父目录 `agent/`）；门禁覆盖扩到 `INDEX.md`／`gate-summary.md`／`agent/cards/`／人读主件，卡面 0 卡的静默通过路径被显式报错取代。代价与已知：历史包在新门禁下带未过读数（形态不同），按 ADR-0008 留档不追改；`run/` 件依赖网络重取，跨跑字节不复原，故擦除演练按输入哈希分流；`docs/adr/` 既有 0023 双号事实继续登记不修（本 ADR 取 0025，0023／0024 不复用）。
- 交叉引用：ADR-0010（workspace 持久化合约；命名版本、跨交付复用形态 B、`run/` 位次与进版例外、清理与配额仍以它为家，本次只由末条窄修订条取代上述四处并互指）、ADR-0009（词／做法／决策三分工：本 ADR 只记决策，做法在 `references/protocols/workspace-guide.md` 与 `reader-html.md`）、ADR-0016（横切规则不占 Step 号）、ADR-0017（`references/` 按职能分桶与 `K-01`）、ADR-0008（历史包基线读数留档口径）、ADR-0023（可及性清单与覆盖账，人读主件读其读数）、ADR-0006（灰色口径，台账口径版本不变）、ADR-0032（队列即研读选取集：决定 6 的 `agent/download-queue.txt` 定义随之改写，与本记录互指）。
