# ADR-0024 引文扩展摄入过滤：被引下限＋分龄豁免、只作用于引文扩展池

- 日期：2026-09-19；状态：已接受；来源：grill-with-docs 会话（六轮批式拷问＋一次真跑实测；证据产物 `tmp/grill-pool-filter/`，命令与读数在会话记录与设计树内）。
- 上下文：引文扩展轮把 LDL-C 交付从 16 池／574 条推到 51 池／2249 条（终池 433→1765，×4.08），触发「池是否膨胀过度、是否该按相关性／被引再过滤一道」之问。实测否决了两个前提：①**队列未被稀释**——有／无扩展两次 v2 队列的 `s_rel` 分布逐位相同（min 0.2／中位 0.6／p90 0.8，`rel=0` 皆 0 条），换榜 57 进／57 出且进出者分布相同；②**形态过滤无效**——最小非证据类型集（editorial／comment／letter／paratext／erratum）＋无题名合计仅减 15/1675＝0.9%；③**词面阈值不可用**——扩展记录 `abstract` 恒为空串（`openalex_record()` 硬编码），`s_rel` 上限钉在 0.6，`rel≥0.5` 只放行 12/1421 条且会滤掉全部 5 条 fixture 经典。真实代价在体量与形状：`raw/` 2.56MB→48.8MB（×19）、Step2 4.4s→82.6s、`step1-pools.json` 2.3→4.06MB；扩展的净收益是捞回缺席经典（AFCAPS/TexCAPS 由不在池→order 243 进队列）。
- 决定：
  1. **位置**＝摄入时（引文扩展记录入池前）；**范围**只限引文扩展池——检索池与追加轮池不动（A-01 基线可比；追加轮是实体驱动定向检索，是低被引新证据的解药）。
  2. **判据**＝被引下限 `cited_by_count ≥ 100`，惟**发表年份落在近 3 年（含当年）者豁免**；两条都不满足者不入池。
  3. **缺值**：被引读数缺失一律不入池（fail-closed，全通道含 EPMC——其 `citationCount` 恒为 None，事实回归「纯读数通道」）；**年份缺失按「新」走豁免档**（保持未知不猜测，但不因未知而杀）。
  4. **上限与截断口径不变**：上限仍按取回条数（前向 ≤100／后向 ≤50 per seed per direction），不补取；「截断」保持「源侧可及但未取」原义，被滤条目另计 `filtered`（按方向×类型分列）。
  5. **默认开启**，`--no-filter` 可关；关闭时读数记「未过滤」，不记 0。
  6. **留痕**：被滤条目落机制读数件 `filtered[]`（id／题名／被引／年份／方向），并进覆盖账与 §8 分句；口径随 `filter_policy`（版本＋阈值＋豁免窗口＋范围）落盘，跨交付可比。
- 备选未采纳（均带实测依据）：形态过滤（减量 0.9%，不治膨胀）；词面相关性阈值（扩展记录无摘要，误伤全部 fixture 经典，`rel≥0.66` 通过 0 条）；被引绝对 ≥100 不设豁免（净损失 18 条队列条目／交付，含 2025 AACE 指南（被引 69））；`cited≥50`（净损失 4、减量仅 45%）；主题内分位线（跨交付不可比）；补取凑满上限（吃 300 预算、读数跨交付不可比）；两机制池同口径（拆掉实体检索解药）；「只计数不留清单」（被滤者可能是尚未成熟的新证据，不可无从复议）；raw 体积压缩（可回溯优先）。
- 后果：按本口径，LDL-C 交付上扩展独占 1322 条中 194 条被滤，**净损失 9 条队列条目（2020–2022 年、被引 50–99 的中被引文献）**，新证据与经典全保。配套两票（会话决议，另行开票）：①扩展记录摘要重建（`abstract_inverted_index`，零额外请求；恒空摘要同时压低相关维与完整度维）；②机制贡献归因（`origin` 记最先入库池，136 条扩展出处队列条目中 76 条标成 discovery，账上会少算扩展贡献）。
- **2026-09-20 复测与配套票状态（ARNI CKD 交付 2026-09-19，grill 会话二）**：**①「扩展稀释队列」的假设在本交付同样被实测否决，且方向相反**——扩展独占 365/520（70%）＋共贡献 60＝贡献 425/520，但池内去扩展独占的反事实只剩 303 条（连 350 的推荐档都凑不满）、rel 均值 0.430（实际队列 0.547）、rel=0 条目 37（实际 0）；**②提高下限换不来更相关或更小的队列**——T=200/300/500 分别只删 37/65/89 条（被删者 rel 均值 0.561/0.542/0.506 ≈ 队列均值，且是旧文高被引、被引中位 128/172/234），递补条目 rel 均值 0.318/0.342/0.334（更差），队列 rel 均值 0.547→0.529/0.522/0.517；池仍余 1441/1361/1284＞520 故**队列规模不变**——队列大小由覆盖深度规则（ADR-0019「队列覆盖位次」）与目标/获取率取大决定，不由此下限决定，**本轮拍板：下限不动**（`hitl-protocol.md` 规模确认节「队列来历」行据此出示三分量与扩展贡献读数）；**③配套票状态**：①已关闭（`.scratch/citation-ingest-quality/issues/02-…`）——本次运行 `abstract_rebuild` 读数 rebuilt 1349/1782＝75.7%、missing 433（24.3%），扩展条目 rel 上限已解（队列内扩展独占 rel max 1.00、=0.6 计 0）；②已关闭（issues/03-…）——账内 `contributed_queue_kinds`／`contributed_queue_origins` 在场（本交付：扩展独占 365＋共贡献 60）；集成验收 04-… 与上层 PRD 均 closed。**残余（记为后续、不即时补）**：missing 433 条无摘要记录的 rel 仍被低估，若补走 Crossref/PubMed 通道（新增请求成本与失败面待测），先在小池实测再定。
- 接口注意：过滤发生在取数之后，**不省请求、不省配额**；覆盖账 `truncation` 口径不动，新增 `filtered` 计数与 `filtered[]` 清单指针；高被引缺席核对以终池为对账基准，被滤条目不被该通道看见（其被引在下限之下，本不在其 top-N 视界）。
