# ADR-0002 批量入库一次确认写库

- 日期：2026-09-16；状态：已接受；来源：04 号票 live exchange（承 placement strong rule、import-runbook 错位先例、03 §4）。
- 上下文：placement 要求一次确认后才写库；CONTEXT.md 静默放置面向人工日常习惯；批量链路两者冲突。
- 决定：经 skill 链路批量入库时，一次确认优先于静默放置（候选 2–4 个，首个为推荐位，一律确认后写库）；人工日常单篇仍沿静默放置。
- 后果：CONTEXT.md 增补“批量链路确认优先”；批量脚本先 `--dry-run`；落点回查与计数校验为准；HITL-3 精化单开 06 号票。
