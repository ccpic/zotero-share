# ADR-0010 workspace 持久化合约：命名版本、单源派生、三件合约、边界台账与封顶

- 日期：2026-09-17；状态：已接受；来源：`.scratch/workspace-spec/` 路线图五票冻结（01 产物清单、02 薄厚原型、03 命名版本、04 边界与台账、05 驱动归属）及其落地票（01–06）。
- 上下文：医学知识包全链路（发现、分桶、下载、入库、研读，外加中文手动补充与监管直取）的 topic 产物此前无持久化规范：中英命名运行池并存、同一证据表存两份、单卡与合卡各存一份，几百兆正文与缓存靠「从未 `git add`」偶然留在版本控制之外，`.gitignore` 无任何相关条目。多 topic 在仓库内何处落盘、目录叫什么、一次交付由哪些文件组成、重跑是否覆盖、小文本与 PDF 各走哪条版本策略都没有锁死，一次误操作即可把正文与缓存全部带进版本库。
- 决定：
  - 命名与版本：根冻结为仓库根 `workspace/`；目录形 `YYYY-MM-DD-<slug>`（日期为交付日期，`slug` 小写英文 kebab `[a-z0-9]+(-[a-z0-9]+)*`，禁中文、下划线、空格，日期与主题两要素必含）；版本取 topic 级新目录——每次重跑建新目录、日期取该次交付日期、旧交付不可变、版本不进 `run/`；同日同 slug 重跑自第二次交付起追递增后缀 `-rN`（当日第二次 `-r2`），跨日重跑只换日期不追后缀，不同研究问题撞主题加长 slug（加人群/干预限定词）且禁用后缀，任何情形禁语义版本后缀；重跑后缀只进目录名（`manifest.json` 的 `topic.slug` 记主题 slug、`topic.dir` 记完整目录名）；`run/` 内命名统一英文 ASCII、小写（词形 kebab；DOI-slug 以 `_` 连接 DOI 与 slug），禁中文；商业库导出原文（`b1-<库>-export-<YYYYMMDD>.txt`）放 topic 顶层、不进 `run/`。
  - 单源与派生：证据表只存一处——知识包 §5 内联为 canonical，运行期草稿表永不进版；提取卡单卡 canonical（`cards/<DOI-slug>.md`，一篇一卡，文件名即寻址）；合卡只作派生件（标 `derived from … via <CMD>`，执行体与机器禁读，由单卡原样再生）。
  - 三件合约：`INDEX.md` 单件双层（人读地图在前、agent 查询式在后）为该 topic 唯一入口，查询只查版内表、不查被忽略收据，厚件禁整读（200KB+ JSON 必 `jq`、400+ 行台账必 `grep`）；`manifest.json` 记全部被忽略件的再生命令 + 哈希 + 台账指针 + 派生标记；`gate-summary.md` 常驻（人读 verdict 头 + 全量尾），门禁全量只经 manifest 指针定位。
  - 边界与忽略语义：进版只限小文本（索引、八节包、单卡、派生合卡、检索策略、筛选日志、分桶与来源台账、落点计划、引文表、监管补充、门禁摘要、再生清单、身份列表、商业库导出原文、监管版本记录）；忽略抽取文本、下载正文、原始池、去重与分桶中间报告、选取过程件（`run/b1/selection.json`／`sort-report.json` 一类；原「中间队列」措辞由 ADR-0032 取代——队列件 `agent/download-queue.txt`＝研读选取集＝入库集，属 `agent/` 进版件而非忽略件）、下载与身份核验与写库收据、库快照、复核文本、门禁全量、运行脚本；唯一例外为监管原文 PDF（字节留档，其哈希记入版本记录）。`.gitignore` 顺序即语义（作用域只限仓库根 `/workspace/`）：先全忽略 workspace 下 PDF → 再忽略各 topic `run/` 内容（忽略内容而非目录本身，否则其下否定全部失效）→ 两级否定先捞回 `run/b2/` 目录、再捞回 `run/b2/ema-*-spc.pdf`。历史包与上游发布件不受新规则影响（已跟踪文件不被驱逐）；被忽略件一律凭 manifest 再生。
  - 台账口径：下载台账逐条路由行（`DOI｜桶｜预计来源｜实际来源｜采用｜未采用原因｜grey_hit｜身份核验｜文件｜口径版本`），身份核验行内只记短串（结论、核验时间、方法），完整证据留在被忽略收据、manifest 记其哈希；口径版本区分 `pre-0006-oa_first` 与 `post-0006-fastest` 两个时代（历史包报告原文不动，只加文件头口径注记）。落点计划表在既有列外增纸张身份（DOI）列作按身份检索主键，附件列逐条记已挂 basename 或无文件去向，表尾计数行是被忽略写库收据的版内投影。监管版本记录冻结在 `source/document/identifier/version_pin/effective_time/set_id/archive/archive_sha256/scope`（版本钉读数为官方页面读数）。join 键：DOI（下载台账）→ 条目键/DOI（落点表）→ Zotero children（附件回查）；三处字节位置（仓外抓取缓存、知识库本地附件、仓内台账）各归各，真源不存两份字节。
  - 版内封顶：单 topic 版内 ≤~35 文件、约一到二兆量级（基准 ~1.5MB，含派生合卡实测 ~1.7MB/31；`step1-pools` 等原始池不计入）；顶层 ≤12 条目。
  - 驱动分层：根 `AGENTS.md` 只留薄指针（根名、日期主题目录形态、重跑新目录不覆盖、混合原则一句话，外加指南与本记录指针，不写死数字与字段）；细节全进 `med-lit-review/references/workspace-guide.md`（唯一家）；skill 主文档只加一行指针；权威脚本家为 `.claude/skills/med-lit-review/scripts/`（workspace 内 `run/scripts/` 为忽略副本，示踪时代旧脚本废弃指新位）；灰色措辞按 ADR-0006 默认启用对齐；历史包内容冻结，只加口径注记；规范文本不进确定性复核脚本与门禁执行器（不新增 workspace 结构断言），不建跨 topic 全局索引（`ls workspace/` 即全局视图）。
- 备选（未采纳）：单目录内版本后缀（`vNN`，旧版寻址多一层）；运行缓存内版本（`run/run-YYYYMMDD-NN`，版本进 ignore 等于不留档）；语义版本后缀（`-vNN`，重跑不是 API 兼容承诺，属伪版本链）；全局跨 topic 索引（单 topic INDEX 定向已自足，topic 增多由执行侧按需生成）；保留运行期草稿表副本（同一表两处必然漂移）；门禁与复核脚本内新增 workspace 结构断言（规范文本不进执行器）；历史包内容迁移或改写（归档冻结，只加口径注记）。
- 后果：任何新 topic 按同一形状交付——版本控制只见小文本（约一到二兆量级），被忽略的一切凭 manifest 再生，旧交付永远可寻址，平行 topic 不碰撞；`run/` 不再承载版本身份；历史包与既有归档不受新规则驱逐；`.gitignore` 下误 `git add .` 也不再带进 PDF 与缓存。代价明示：缓存缺席时逐条去重轨迹审计退化为版内计数 + manifest 再生链（如需 condensed trail 另议）。
