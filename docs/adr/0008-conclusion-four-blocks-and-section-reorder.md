# ADR-0008 交付物结论形态：§6 四块结构与结论前移

- 日期：2026-09-17；状态：已接受；来源：grill-with-docs 五轮（实施票 `issues/12-conclusion-order-and-four-blocks.md`）（2026-09-17，batch；议题＝结论的位置、口吻、证据密度与空白边界），承 ADR-0003（主题式综合替 Gap 章节）与 01 号票 live 决议。
- 上下文：初版按 01 号票把结论放证据表之后、只列行号指针，实交付读起来是「先翻证据表、再看结论」，且内容过简（无总体判断与关键数值、无趋势/争议/空白）；同时 skill 内硬门禁 L-03（error；扫「执行摘要／主题式证据综合／结论」三节散文）要求实质断言句带引文或行号——与「核心段带数字但不写行号」直接相抵。另：01 号票冻结过「八节顺序固定」与「不设研究空白与未来方向章节」，本决定两处都触碰，故立此 ADR 留痕。
- 决定：
  1. **顺序**：八节改为 执行摘要 → 研究问题 → 检索策略 → 主题式证据综合 → **结论** → **证据表** → 方法附录 → 局限声明（结论与证据表换位，其余不动）。
  2. **§6 固定四块**（三级小标题 `### 6.1 背景` / `### 6.2 核心结论` / `### 6.3 讨论` / `### 6.4 支持结论`）：6.1 写疾病负担、病理生理、靶点生物学与涉及药物的一般事实（作用机制／药物类别／给药途径类别／药代定性），内容须出自本包纳入文献；6.2 写对 PICO 的总体判断（主流趋势＋证据空白与待补证据），≥300 字，允许效应量类数字但不写行号；6.3 写对本包结果的解释与机制推理并承载争议与矛盾；6.4 为平铺支持条目 ≥5 条，每条＝可核判断＋关键数值＋证据表行号。
  3. **口吻**：6.1–6.3 用循证综合／discussion 口吻（客观第三人称；禁逐篇叙述、方法学评述、文献史）；药物相关内容只写定性背景，禁剂量与适应症／禁忌／用法用量等规范性断言（规范性内容走 §5 监管行与 6.4 条目）。
  4. **空白边界**：允许写「证据空白＋不确定性＋要回答还需什么证据」（本次交付口径）；**不写**学科空白与未来研究方向——ADR-0003 的「不设 Gap 章节」在此边界内不变，仅把「证据空白」正名为可写内容。
  5. **豁免与补偿机验**：6.1–6.3 豁免 L-03／L-08（不写行号）；补偿为三条新 error 规则——M-01（6.1／6.3 出现数字）、M-02（6.2 的效应量类数字在证据层 §4／§5／6.4／引文表 查不到；年份、试验代号、监管文号等标识符内数字豁免）、M-03（§6 四块要素不全）；6.4 条目不豁免。6.1／6.3 的「出自本包文献」由行为规则＋R4 自查逐段抽样 ≥3 条留痕（指针入包）承担。
  6. **门禁**：验收门禁新增断言——节序（结论在证据表之前）、§6 四块齐、核心结论段下限与要素、核心段数字可在证据层查到、支持结论条目全带行号；历史包（tracer／blind，旧顺序）复跑时顺序断言会提示，归档注记「顺序断言自本轮起」。
  7. **术语归属**：核心结论段／支持条目／证据空白／机制背景段等为 skill 内执行词，落 skill 内 glossary（`references/conclusion-template.md` 首节），不进 `CONTEXT.md`（沿 10／11／13 号票先例：放置词汇表只收 Zotero 放置词）。
- 后果：交付物第一屏即结论，读序从「表→结论」改为「结论→表」；核心段（叙述）与支持条目（可核）分工明确；防编造由「全篇带行号」改为「分区规则＋数字可查＋条目行号」，L-03 的意图（无无据断言）由补偿机验接住；§6 结构由确定性脚本与验收门禁双层守（M-03＋门禁断言）；历史包在新门禁下顺序断言会失败，属预期并已注记；本轮只落设计（ADR＋PRD＋实施票），实现另按票执行。
- 备选与否决：（a）把核心段并入 §1 执行摘要——否：结论仍离证据表更近才有意义，且与 §1 导语会重复；（b）核心段保留行号——否：与「核心段是叙述」相冲突，改用豁免＋补偿；（c）放开学科空白与未来方向——否：维持 01 号票 live 决议，只允许证据空白与待补证据；（d）机制段允许带剂量／适应症等规范性内容——否：与「监管限规范性断言」的双轨口径冲突。
- 修订（2026-09-17，references 分桶，ADR-0017）：术语归属一节的路径变更为 `references/templates/conclusion-template.md`；本节所定 §6 四块口径、门禁断言与豁免补偿机制均不变。
