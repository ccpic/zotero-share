# ADR-0030 文献关系图的呈现重构：扇面布局、可读性预算、本包相对尺寸与边走廊

- 日期：2026-09-20；状态：已接受；来源：文献关系图「60 个点几乎不可读」的 grilling 会话（先对唯一带图数据的在版交付 `workspace/2026-09-19-arni-ckd-proteinuria/`（120 节点／250 边）做几何与渲染实测，再五轮逐项拍板：17 项决议）。**取代 [ADR-0027](0027-graph-year-bands-and-neighbourhood-layer.md) 决定 3 的「默认展开」与[工单 03](../../.scratch/workspace-output/tickets/03-relationship-graph-design.md) 的 §5 布局几何、§4 大小映射、§8 上限常量**；ADR-0027 的年份档（决定 1／2）与「邻域层＝背景层」（决定 3 前半）继续有效。
- 上下文：实测（viewBox 1200×900，实渲 1152×864 CSS px，`userUnit` 0.958）暴露五件事。① **把 2D 画布当 1D 弧长用**：主节点恒在 `R=150` 单圈、邻域 `210+52k`，环半径是与点数／点径／画布无关的绝对常数；墨水只占画布 41.6%×59.7%（面积 24.8%）；`fit_view()` 的 scale 夹在 0.5–1.0（**只缩不放**）；60 个主节点单圈弧距约 11.8uu，实测 8 对圆相交（最差间隔 12.3uu，半径和约 12.5uu）。② **容量账方向反了**：单圈容纳 60 点需 `R≥210uu`（画布高 47%）、留可读间隙需 `R≥286uu`（64%），再叠邻域环外径即 840/900uu；而同样 120 点按 2D 排布只需 242×242uu。**点从来不是瓶颈（120 点只占 2D 容量的 1/5–1/3），边才是**——250 条边里 153 条是穿心长弦（中位 170uu、p90 293uu）。③ **尺寸通道不可辨**：60 个主节点落在 47 个直径（5.7–16.5px），286/1770 对差 <1px；映射域取本包 `min/max`（[2, 64116]＝4.5 个数量级），10 倍被引差只换约 3px 直径；且 `node_radius()` 让 `c≤0` 与「缺值」共用兜底 `r=4.0`，**比 `c=2` 的 `r=3.0` 还大（编码倒挂）**。④ **半数主节点无名**：点号只给 `r≥5.5`，实测 29/60 带号，25 个证据行在图上是无号点。⑤ **邻域层大半是装饰**：边按 `max(节点序)` 升序截断而主节点序恒在前 → 153 条主-主边全保、邻域边被系统性砍掉，`isolated_kept=52/120`，**45/60 个邻域点一条边都没有**。另有五处缺陷：4 条自环边（`source==target`）画成 0 长度线；12/120 个命中圈小于可见点（点边缘不可点）；簇标签定位用硬编码中心 (600,450) 而真实布局中心是 (542.1,501.7)（偏 77.6uu，折叠后标签被 viewBox 裁掉）；簇标签文字含 `§4.x`（违 `reader-html.md` 义务 15「主题在读者面一律写名字」）；`.graphwrap`（两列 2.1fr/1fr）是死码——渲染器从未发出该元素。
- 决定：
  1. **布局改「扇面」（面积式）**：主节点不再排单圈，改在各自主题扇区内按子环铺开（环带半径由点数与最小可视间距反推）。**扇区张角按面积分配**（`Σ 点数×单点方格`），取代「3×主＋邻」启发式——新尺寸下主／邻单点方格是 3600/676＝5.3×，旧权重不再成立。
  2. **环带椭圆化铺满**：半径按 `a=554 / b=404` 映射（可用区 1108×808、边距 46）。实测收益：总面积 512,758 → 703,139 uu²（**+37.1%**）、主带行数 **60.1 → 86.6**（+44.1%）。理由：圆内切于 4:3 画布只用到宽度的 73%，且**本包 60 行在圆映射下已占主带 99.8%（零余量）**——椭圆化是这套尺寸能成立的前提。代价：同一环上横向间距是纵向的 1.37 倍，单点方格按最紧方向算、标签避让按实测距离判。
  3. **带序（内→外）＝主带 → 邻域带 → 边走廊 → 主题标签圈**，半径按**展开态**一次定死（走廊 88uu、标签圈 30uu 为纵向占用）；折叠只换 viewBox，不重排。
  4. **可读性预算取代固定点数上限**：判据＝画布可用面积 ÷ 单点方格（点径上限 46px ＋ 行号占位 14uu ＝ 60uu）；旧常量 120/250 退为硬兜底并随数据块落盘。**主节点全收**（守「每行一篇」契约，实测 60 行用掉椭圆主带 69.3%）；邻域只收「至少有一条被画出的边」者；超容量时**先不画邻域层、再按预算收缩直径量程**，主节点永不截断，降级事实进 `graph_truncated`。
  5. **尺寸通道＝幂 `p=1/3` ＋本包 `min/max` 域**（`r ∝ c^(1/3)`，量程 14–46px）。买到的：**顶端主导 2.45×**（对数同域只有 1.60×）；代价明写：**低段塌平**（1 被引 10.0px vs 10 被引 11.4px 在尺寸通道不可分）。同一量程下的对照：原值线性 31% 可辨对、平方根 52%、立方根 61%、对数（本包域）75%、对数（固定域 [10,10⁴]）76%、分档量化 72%——即「原值与对数之间」的任何 `p<1` 都更差，本决定是**按「顶端主导优先」拍板、明知代价**的结果。域取本包 ⇒ **跨包不可比**，故图例必须写明「大小＝本包内相对被引数，跨包不可比」（保真度约束的新实例；与年份档的绝对日历档界相反，同图两种口径）。
  6. **缺被引数单列一档**（固定最小号＋空心问号描边，不进任何数值档），与 ADR-0027 决定 2 对缺年的处置同构；`c=0` 归最小档，**修掉编码倒挂**。
  7. **每个主节点都带行号**：圆内放得下就放圆内（字号下限 11px）、放不下外置到圆外（四向固定次序避让）；占位计入单点方格 ⇒ **由布局负责保证放得下**，不再出现「放不下就静默不标」。
  8. **走廊按主题对聚成带**：跨主题引文边**不画独立弧**（实测 151 条各自分开需 151–302uu 走廊宽，而画布半径只有 404uu；走廊 226uu 时主带只剩 R=124、仅容 13 点），改按主题对聚成 **11 条带**（4.2–4.3 56 条、4.2–4.6 19、4.1–4.5 17、4.1–4.2 16、4.3–4.4 11、4.3–4.6 11、4.2–4.4 8、4.2–4.5 8、4.1–4.4 2、4.4–4.6 2、4.3–4.5 1），**带宽 ∝ √条数**（面积同比，只 1 条的带也不消失），带两端各打一枚主题色端点、带上标条数。个体引文降为悬停／读数。
  9. **簇内定序改纯函数贪心**：起点（被池内引用计数 desc → 被引数 desc → DOI），其后每步选「与已放点相连最多 → 被池内引用计数 → 被引数 → DOI」；取代 `(year, DOI)` 定序，主-主边由长弦变短边。**同簇内弧序不再等于年代**（年份只走透明度档）；可推导、门禁可复算（否决不固定种子的局部优化）。
  10. **默认只画主节点**，邻域层改「展开相邻文献」按钮（**取代 ADR-0027 决定 3 的「默认展开」**）；**两态位置恒定**（折叠＝纯缩放，主节点坐标一致），外弧带放不下就减邻域点数、不压缩主节点。同时修掉折叠态的 viewBox 与主题标签裁切。
  11. **门禁改判几何不变量**（取代「节点 ≤120／边 ≤250／`caps` 与常量全等」）：主节点数＝证据行＋背景卡数、任意两点不相交且行号不与邻点重叠、所有点与标签在画布内、点直径与被引数按口径可复算一致、截断与降级事实在场。
  12. **邻域层用独立小刻度 8–20px**：实测同刻度需与主层等面积（−33uu，装不下），且同尺会让背景点在视觉上与主节点争地位。邻域仍恒中性色、不给落点。
  13. **顺带修五处缺陷**：自环边（`source==target`）出图前剔除并进读数；命中圈不小于可见点且不超过最近邻距的一半；簇标签中心改从布局自身推导（不硬编码）；主题标签按读者面口径去掉 `§` 号；`.graphwrap` 死码删除。
- 被取代的旧条款：ADR-0027 决定 3 的「默认展开」（由本记录决定 10 取代；背景层定位与整层折叠开关保留）；工单 03 §5 的「主节点内环 150／次级 210 起每层 52」与「簇内按 `(year, DOI)` 定序」（由决定 1／2／9 取代）；§4 的「节点大小 `r = 3 + 7·log 归一`、缺值 `r=4`」（由决定 5／6 取代）；§8 的「≤120 节点／≤250 边」作为唯一边界（由决定 4 取代，常量退为硬兜底）。年份档（ADR-0027 决定 1／2）与「邻域层＝背景层：不承载主题色、不进键盘与 AT、不给手型」继续有效。
- 备选（未采纳，均带实测理由）：**保持单圈环、只调常数**（60 个主节点仍需重叠，圆映射下主带已零余量）｜**主题分带／分列**（铺满更好，但 151/250 条边跨主题会长横线穿整图）｜**分主题小图 2×3**（跨主题关系在细节图里丢失＝主题分区视图的唯一价值消失）｜**保留 120/250 常量**（与像素预算口径互相打架：预算说能放 300、常量说只能 200）｜**只画短边**（自动且无新常量，但跨主题长边被系统性丢掉——那正是主题分区视图看不出来的结构）｜**平均度预算 ≤6**（按度裁边会裁在信息量上，而长度与信息量无关）｜**边改「聚焦才画」**（静态图与打印件彻底没有关系可读）｜**对数＋固定绝对域 [10,10⁴]**（可辨对 76%、跨包可比；按「顶端主导优先」未采纳，对照见决定 5）｜**分档量化（4 档绝对档界＋档内摊分）**（可辨对 72%、每点可命名、与年份档同构；未采纳）｜**直径量程 10–34／12–40／8–28px**（可辨对 62／66／57%、主带容量余量不同；取 14–46px 以顶端可辨为先，容量由椭圆化补回）｜**邻域层沿用同一尺寸刻度**（需与主层等面积，−33uu 装不下）｜**邻域层固定小号或改计数刻度**（省面积，但邻域的影响力读数从画面上消失）｜**走廊画 151 条独立弧**（算术不可行，见决定 8）｜**走廊与邻域带共用一圈**（主带更大，但展开态线与点相叠）｜**展开时重排／两态各一套坐标**（位置漂移，与「同输入同字节」承诺及本图既有的反对漂移决议张力大）｜**拆成三份 ADR**（互指更多，读者要拼三份才看全）。
- 后果：渲染器改写六处（`layout()` 改扇面＋面积权重＋椭圆映射、`fit_view()` 双向铺满、`node_radius()` 改幂映射并单列缺值档、`graph_svg()` 改带序与走廊带、折叠 JS 改纯缩放、图例与自述文案）；`reader-html.md` §3.6 与义务 14／15 同步改写；`check_delivery.py` 的 W-07 与 `NODE_CAP`／`EDGE_CAP` 改判几何不变量；工单 03 就地加指针。已知代价：① 尺寸口径本包相对 ⇒ 跨包不可比（图例必须写明）；② 低段（≤10 被引）在尺寸通道不可分，只能靠行号与悬停；③ 走廊带只承载主题对聚合，个体引文降为读数；④ 极端大包（>约 87 个证据行）要先失去邻域层、再失去尺寸量程。历史交付（arni 之前的包）冻结不动，最多加口径注记。
