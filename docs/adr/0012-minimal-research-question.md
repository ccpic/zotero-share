# ADR-0012 研究问题退至最简：一句话系统化问题＋入口确认（取代 ADR-0011）

- 日期：2026-09-17；状态：已接受（取代 ADR-0011）；来源：grill-with-docs 会话（价值审判两轮＋最简形态一轮，用户三次收敛）。
- 上下文：ADR-0011 在 PICO 之外引入三框架目录＋判定映射＋入口框架确认。随后用户质疑「把研究要素框住的获益到底有没有」。事实核对：Cooke 2012 把 SPIDER 定位为检索工具；Methley 2014 显示框架可测地改变检索结果（PICO 敏感度更高、SPIDER 特异性最高但漏检风险大），但**非越贴切越好**；本实现中框架名只驱动 §2 命名与关键词分组，发表类型筛选、E1–E5 分级、七列表、结论数字口径都不按框架分派；框架名在用户工作流中无独立用途。第一轮先退为「属性驱动」，随即用户再退：属性驱动也不要——目标只是「问题好检索、好回答」，避免过强过细约束。
- 决定：
  - 删除框架目录、判定映射、属性分派、要素槽位与框架名：§2 只记一句系统化研究问题（关键词与边界住检索策略节）；不要求要素条目、不校验槽位、不记属性标签。
  - 入口保留「研究问题确认」一问（紧随路线问）：一句话＋关键词/边界只读附注＋两选项（照此／改写）；AFK 按拟稿继续、断点记日志。
  - 结构负担从用户挪到 agent：agent 拟稿；仅当问题不可检索/不可回答时追问一次（自然语言一句，最多一次）；自检记一行「问题自检：可检索 ✓｜可回答 ✓」入检索策略节。
  - 校验：ST-02 改为「缺研究问题陈述」——§2 内有问句（含「？」）或有「研究问题：」标签行即算在；否则 warning。旧形态（要素条目、PICO 挤写）不留兼容分支，由离线迁移消化。
  - 关键词表可缺省：用户可给可不给；缺省由研究问题推导（来源记「推导」）；概念组内 OR、组间 AND 的检索组合口径保留在检索策略模板（原目录文件删除）。
- 备选（未采纳）：三框架目录＋判定（ADR-0011；装饰层，机制不按框架分派）；属性驱动（分水岭属性确有检索差异，但对用户是新概念负担，且 PEO 与 PCC 之间检索近似同构）；维持 PICO 单框架（非干预类问题无表达）；零交互（误读原始提示词的风险全由包承担）。
- 后果：文档与脚本回退至最小形态——CONTEXT.md 只留「系统化研究问题」一词；`references/question-frameworks.md` 删除；hitl-protocol／search-strategy-template／review-rules／脚本 ST-02／两条夹具与行为用例同步改写；ADR-0011 状态改「已被 ADR-0012 取代」。
- 修订（2026-09-17，迁移收口）：删除 ST-02 的两条旧形态兼容路（≥2 条要素条目、同行 ≥2 个要素标记）；旧内容离线迁为一句话形态——evals 夹具七件（clean／conclusion-ok／conclusion-m01–m03／lexicon／dirty）、workspace 演示包七件、验收选题的范围要素行去 PICO 标签；历史归档件（blind／tracer 包）内容冻结，按 gate README 归档注记处理，ST-02 命中属预期不追溯。
