# ADR-0006 灰色渠道原文获取默认启用（全量，含 Tor）

- 日期：2026-09-17；状态：已接受；来源：grill-with-docs 会话（两轮 11 问 live exchange）——用户逐项拍板并明确接受代价，构成 ADR-0004 的「签字式确认」。
- 上下文：ADR-0001 锁死「默认链路与 e2e 默认路径不进灰色」；ADR-0004（提案，未接受）只提「仅 e2e 允许灰色 fallback」；用户在 05／06 号票 live exchange 中一贯坚持灰色默认开启。本轮用户要求把 `.claude/skills/med-lit-review` 的灰色渠道原文获取改为默认开启。
- 决定：灰色源（Sci-Hub 等）与 Tor/反爬路线**全量默认启用**（所有运行，含无人值守）：
  - 下载默认走竞速（`fastest`，含灰色）优先拿到原文；免费／仓储／出版商接口／机构授权路线为并列通道；以灰色最快命中为准。
  - 交互点一（灰色桶确认问）废止：不再打断、不再有「每次明确选择」与「当次授权」语义；AFK 照走灰色与 Tor。
  - 机构登录（交互点二）保留为两处断点之一，触发条件改为「含灰色在内仍没拿到」；推荐位仍「先不登录」；未勾选通道与设置改动一律不动。
  - 启用机制：`scansci-pdf` 全局配置 `scihub_enabled=true`（本机全局，其他 skill 同受影响——用户已确认）。
  - 报告纪律：逐篇实际来源如实（含灰色与 Tor 路线）；报告须声明灰色渠道口径；机构登录与设置改动仍零静默。
  - 代价接受（用户签字式确认）：① 灰色默认动作的版权与规则风险由用户承担；② e2e 固定集可复现性下降——灰色命中只断言「如实报告」，不锁定具体来源；门禁同步改写（C-02/C-03/C-06/G-01/G-02/H-06；开放类锚点放宽为「成功且来源如实」）。
- 后果：ADR-0001 被本 ADR 取代；ADR-0004 提案被并入（未采纳「仅 e2e」窄口径）；skill 语料与验收语料同步（`.claude/skills/med-lit-review/` 五件＋走查矩阵四件）；轻量验证＝门禁自检 4/4、存量归档兼容复跑 78/78×2、真实试点 3 成功＋1 如实失败；CONTEXT.md 不动（无新放置术语）。
