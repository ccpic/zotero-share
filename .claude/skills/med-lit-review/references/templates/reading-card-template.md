# 提取卡模板（reading-card-template，研读唯一输入原文）

本文件是每篇一卡的执行唯一来源：每篇文献一张提取卡（extraction card），卡是主题综合的唯一输入，未建卡文献禁入综合与证据表可追溯列。卡建完跑防臆断清单，综合写完跑研读完整性硬规则 R4。

## 1 模板（复制即用，每篇一卡）

```markdown
## 提取卡 <卡号，如 G1／R1a／ZH3>：<作者年份短引>（全文状态：有全文 PDF p.X–Y / 仅摘要 / 仅题录）

- 标识（identity）：作者 | 年 | 标题 | 期刊/文号 | DOI（数字对象标识符，Digital Object Identifier）/PMID（PubMed唯一标识，PubMed Unique Identifier）/监管文号 | 指南版本号·说明书版（如适用）
- 研究要素（人群 Population / 干预或暴露 Intervention or exposure / 对照 Comparison / 结局 Outcome；对应研究问题：…）
- 设计与E级（design and evidence level）：<类型> · E1–E5初判→定级（升降级后）
- 人群（population）：纳入标准 …；n=…；随访 …（观察性加数据来源：理赔数据库 claims、电子健康记录 EHR（Electronic Health Record）/登记库）
- 干预/暴露（intervention/exposure）：剂量/疗程/对照 …（监管文件填“规范性结论”，不填效应比较）
- 结局/效应量（outcomes/effects）：主要终点 …；效应值原样摘录 …（不换算）
- 偏倚与升降级（bias and upgrading/downgrading）：工具 <RoB 2/ROBINS-I/AMSTAR-2/AGREE II>；域评价 …；升/降档理由 …（±1，过时/异质/近2年被超越注明）
- 可引用摘录（quotable excerpts，每条附页码 + 原创/转引 + 原始来源）：
  1. “<原文摘录>”（p.原文X / PDF p.Y，原创 original/转引 re-cited自…）
- 作者自认局限（author-admitted limitations，原文原样）：…
- 与本文关系（relation to this review）：<直接支撑结论 direct support / 背景 background / 存在分歧 tension dialogue / 方法借鉴 method reference / 安全信号 safety signal / 规范性依据 normative basis>；落主题节 <§x>；对应文献 <编号>
- 未见/未知（unseen/unknowns）：[待补充出处]/[待查证]/未见原文（列出具体项，不空填）
```

## 2 填表说明

- 全文状态（full-text status）必填，按 R5 三值取一（`有全文`／`仅摘要`／`仅题录`）：只有“有全文”才填人群/干预/结局细节；“仅摘要”只填标识 + 研究要素（按摘要）+ 未知标注，不拆解。**建卡守恒：建卡 ⇔ 至少读到摘要**（ADR-0023）——`有全文` 与 `仅摘要` 建卡；`仅题录` 不建卡，只进可及性清单、§8 与引文表。
- 摘要取数（`仅摘要` 卡）：三级次序——库内条目 `abstractNote` → 入库摘要表 → 联网（默认联网，`--no-fetch` 显式关；编排口径见 SKILL.md R5a）。研读集内凡无全文的条目**都要走这一遍**（义务，不是许可），三级皆无才判 `仅题录`；逐条读数落可及性清单 `run/step5-accessibility.json`。
- 标识段位置约定（人读主件按位取值，第 7 轮成文）：**第 1 位作者、第 2 位年份、第 3 位题名、第 4 位期刊与年卷页、第 5 位 DOI，第 6 位起附注**（PMID、注册号、资助、许可、日期、「本轮读到」的页等）。分隔符全角 `｜` 或半角 `|` 均可；**位分隔符只在括注外算分隔符**——括注里照录的原文页眉一类（`（原文页眉：Nat Rev Rheumatol | Volume 20 | April 2024 | 241–251）`）写作半角竖线不影响按位取值，但括注须配平（未配平该段整段回退原样）；**第 6 位起的注不得前移**——位置一动，页面上的题名与作者就会取错。第 5 位写 DOI 值即可（`10.1038/s41584-024-01094-9`），带 `DOI` 记号的写法（`DOI 10.1038/…`）同样收；取不到题名的卡改走卡首行兜底，且回退张数与名单会进渲染读数（`reader-html.md` §3.17）——大片回退即卡文件该按本位约定补正。作者位可带通讯作者/单位括注，年份位可带投稿与接受日期括注（页面只取四位数年份）。
- 页码规则：优先原文页码；无原文页码用 PDF 页并注明 `PDF p.`；纯摘要标`摘要`，不编页码。
- 效应量原样：HR（风险比，hazard ratio）/OR（比值比，odds ratio）/RR（相对危险度，relative risk）/CI（可信区间，confidence interval）照抄，不跨体系换算；中文术语后保留英文原名。
- 关系定位每卡一主关系（primary relation），可兼标一次要关系；六类只取其一作主关系。
- 待补占位两种：引文位置用`[待补充出处]`，数字/细节用`[待查证]`；不清零禁入证据表可追溯列。另有内容标记`未见原文`（标“这部分本轮未读到原文”）：它是内容占位词、不是可及性状态值，不进占位判定，不影响进表，但带该标记的行须在 §8 交代。
- 评价语标`本卡判断`，与原文描述分行；区分“作者说了什么”与“这意味着什么”。
- 类型约束：叙述综述（narrative review）只进背景不进表（只填标识 + 背景关系）；病例报告（case report）仅安全性行（结局列只填安全性表型，关联列写“信号待验证”）；监管文件（regulatory document）限规范性断言（结局列填监管结论原文引用）；纯会议摘要（conference abstract）禁支撑结论，与仅题录同按 R5 不进可追溯行。
- 机密不记：卡内不记密钥、登录票据、代理凭证、机构信息四样。

## 3 卡→七列表映射（卡是行草稿，表是交付行，无损搬运）

| 七列表 | 来自卡字段 | 转换规则 |
|---|---|---|
| 文献 | 标识 | 作者年 + 标题 + DOI/文号；指南带版本号、监管带文号与版本日期 |
| 设计与等级 | 设计与E级 | `类型 · E1–E5`（定级后，非初判）；监管注`（规范性）`；可及性状态词一并写在本列（`· 仅摘要`／`· 仅题录`），仅摘要行偏倚列必写「未评（未见全文）」 |
| 人群 | 人群 | 原样搬运；观察性加数据来源括号 |
| 干预与暴露 | 干预/暴露 | 原样搬运；监管行填适应症/用法原文引用 |
| 结局与效应量 | 结局/效应量 | 原样搬运；叙述综述此列空（不进表）；病例只填安全性；监管填监管结论 |
| 偏倚备注 | 偏倚与升降级 | 工具名 + 域评价 + 升降级理由（一行） |
| 与结论的关联 | 与本文关系 | 关系 + 主题节号（如“支撑 §4.2，在研人群外推受限”）；病例写“信号待验证” |

## 4 卡→主题综合输入关系（补缺环，不是新方法）

- 卡是主题综合的唯一输入单位：主题段落只综合已建卡文献，不直接读 PDF 写段。
- 综合时按主题聚卡：同主题卡先列行号，再写主题段，段内每句实质断言点到证据表行。
- 分歧只写主题分歧（topic tension：A说X、B说Y，分歧点在人群/剂量/随访）；缺口只写本次交付局限（查了什么、缺什么、为何缺）；禁写学科空白与未来方向章节。
- 未建卡文献禁入综合；仅摘要文献可进主题综合与结论层，须按 R5 标状态，其行号须在 §8 逐行交代；仅题录与会议摘要不进综合、不进证据表可追溯行（**仅题录不给表留占位行**，按 DOI 进 §8）。

## 附录 防臆断清单（卡建完跑一遍，综合写完跑 R4）

- 每条归纳有页码/段落号（无页码即未完成）。
- 作者观点（author claim）与转引（re-cited）分开：转引数据标原始来源，不算作者原创证据。
- 未读部分标`未见原文`，不凭摘要推正文；引文核对上下文，不断章取义。
- 不带预设拆解：不支持本文的结论也照实建卡。
- 不去限定词：作者写“可能/在某种程度上”转述保留，不升调为确定断言。
