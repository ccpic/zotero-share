# 落点报告模板

写库前先出计划表（--dry-run，即试运行），一次确认后才写库；写完逐条回查，报告以回查为准，不以写入返回为准。

<!-- 注：条目键后第一列是 DOI（纸张身份/join 键：下载台账行 → 本表条目键 → Zotero children 附件回查）；候选落点二至四个，首个为推荐位；确认结果三选一；回查逐条核对收藏集与父条目；附件列写挂载结果（已挂：文件 / 无 PDF：去向）；本次合集列逐条写本次合集挂载（已挂：集名 / 未挂：去向）；摘要列写每篇的摘要落点状态（已填：来源 / 未填：状态 / 不适用）。 -->

| 条目键 | DOI（纸张身份/join 键） | 标题 | 候选落点（二至四个，首个标推荐位） | 确认结果（用户选定、自定位置、留未分类） | 收藏集 | 父条目 | 回查（收藏集与父条目一致 + 计数） | 本次合集（已挂：集名 / 未挂：去向） | 附件（已挂：文件 / 无 PDF：去向） | 摘要（已填：来源 / 未填：状态 / 不适用；来源取 table／crossref／pubmed／openalex／库内，状态取 empty／no-identifier） |
|---|---|---|---|---|---|---|---|---|---|---|
| key | 10.xxxx/yyyy | title | 候选一（推荐）/ 候选二 | 用户选定 | collections | parentItem | 一致 | 已挂：med-lit-review/2026-09-17-pcsk9-ascvd | 已挂：file.pdf | 已填：table |

- 计数校验：计划数 | 写入数 | 回查一致数，三数一致才算收尾；三数与被忽略写库收据 `run/placement-write-report.json` 的 `counts.plan/written/rechecked_consistent` 一对一（收据哈希见 `agent/manifest.json` 的 `receipts` 条目）；**计划数＝研读选取集条目数 − 仅题录成员（同有卡集）**（ADR-0032：该集合在下载与摘要取数完成后即定，与随后产生的有卡集逐条一致；条目集守恒见硬门禁 W-22）。
- 本次合集行（表头一行，D-10 读数位）：本次合集：`med-lit-review/<交付目录名>`｜建／复用／AFK 自动建｜双挂／追挂一致 {M}／{N}（不一致即 D-10 未过）；P2／P3 本行记「不建集（写库设计跳过）」。
- 摘要计数行（D-11 读数位）：摘要：已填 N（table a／crossref b／pubmed c／openalex d／库内 e）／未填 M／不适用 K——已填者库内 `abstractNote` 必须非空（回查口径见 SKILL.md 校验节 D-11）；`库内`＝条目原有正文、本轮未取数，五项子数之和仍须＝N；该词是落点报告的词，不是脚本词——取数脚本的 `source` 取值仍为 table／crossref／pubmed／openalex／none，别往脚本里加；缺口非阻断（未填与不适用不进失败，该记的照记）。
- 摘要口径注记（D-11 读数位，现行包必写）：落点报告头记「摘要口径：present」（本报告带「摘要」列与摘要计数行）；缺此注记者按历史包读（ADR-0008），P2／P3 未写库块按写库设计跳过记。
- 既有条目（库内已存在未重写）：另表列「正文附件：已有 → 跳过 / 无 → 补挂：<文件>」＋「摘要：列值与主表同」（既有条目仅空补齐，口径见 ADR-0021）＋「本次合集：已追挂／未挂：去向」。
- 确认门：先 --dry-run 出计划表 → 一次确认 → 写库；单篇不例外，有人值守未确认不写（AFK 按交互点三回退全自动，ADR-0013）。
- 断点：未分类 N 篇 | 无 PDF K 篇 | 本次合集未挂 L 篇 | 原因 | 缺口去向（局限声明）；有人值守用户缺席或未获确认一律留未分类（含本次合集亦不挂）。

## 未写库块（写库设计跳过；P2／P3 默认，增回写库即转全模板）

- 断点：未写库 {N} 篇 | 原因：设计跳过（{预设}未含写库） | 缺口去向：§8
- 计数校验：计划数 0 | 写入数 0 | 回查一致数 0（设计跳过，非执行零写入）
- 本次合集：不建集（写库设计跳过）
- 「未写库」（设计跳过）与「留未分类」（在组未获确认）严格区分；本块不含计划表、确认列、回查列与摘要列；既有条目附件表只在写库在组时出现。P1 不出落点报告（写库设计跳过只在筛选日志记）。
