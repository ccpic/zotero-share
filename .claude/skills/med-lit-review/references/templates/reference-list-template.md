# 引文与参考文献表模板（GB/T 7714-2015 单制式）

本文件只定引文制式与逐条核对口径。每条实质断言仍点到证据表行；本表只管「怎么著录、核没核过」。数据源优先级 Crossref deposition > OpenAlex enrich > citation(bibtex)（按需取），冲突以 Crossref 为准。

<!-- 注：单一制式，不并行 Chicago／MLA；中文正文亦不例外。 -->

## 1 类型标识与字段

| 类型 | 标识 | 字段式 |
|---|---|---|
| 期刊文章 | `[J]` | `著者. 题名[J]. 刊名, 年, 卷(期): 页码. DOI` |
| 专著／书章节／单行本指南 | `[M]` | `著者. 书名[M]. 出版地: 出版者, 年: 页码` |
| 学位论文 | `[D]` | `著者. 题名[D]. 保存地: 保存单位, 年` |
| 会议文集／会议摘要 | `[C]` | `著者. 题名[C]. 文集名. 出版地: 出版者, 年: 页码` |
| 报告／说明书／审评／通告 | `[R]` | `机构. 文件题名[R][EB/OL].（版本日期）. 文号. 获取路径, 引用日期` |

- 电子载体在类型标识后加 `[EB/OL]`：监管文件、在线首发论文、官网文件一律加；期刊电子版加在 DOI 之后亦可。
- 监管行必须带版本与文号（说明书版本或 SPL 版本＋BLA 号、EMA 修订号＋许可号、注册证号）；未见官方原文时标 `[待核对]`。
- 中文按中文题名与中文刊名著录，英文关键术语保留原文；机构作者（FDA／EMA／NMPA／学会／修订委员会）用全称，首现不缩写。

## 2 著者规则

- 列前 3 位加「等」；3 位以内全列。全 skill 统一「等」，不混 `et al`。
- 机构责任者（指南修订委员会、学会、监管机构）用全称整条作著者，不拆解到个人。

## 3 逐条核对与待核对标记

- 定稿前逐条人工核对：著者／年／卷期页／DOI／版本号／文号，逐条写明核对来源（Crossref deposition／PubMed 记录／期刊官网／官方原文）。
- 未核对条目标 `[待核对]`，**不进证据表可追溯列**；核对后才挂行号。
- 解析失败条目原样退回（含行号与原文本），不猜补；不因个别条目失败而放弃整表。

## 4 表式（复制即用）

| 编号 | 条目 | DOI/文号 | 核对（来源） | 证据表行 |
|---|---|---|---|---|
| R1 | | | 已核对（来源）／待核对 | 行 N 或 — |

## 5 与证据表、断言的关系

- 证据表「文献」列用本表同制式的简式（著者前三加「等」＋年＋刊名＋卷期页或文号），完整条目在本表。
- 每条实质断言点到证据表行；本表行号回指用于核对断链（表有行而引文缺失，或引文有而表无行，均需在局限声明交代）。
