# 人读主件渲染契约（reader-html）

本文件是人读主件**渲染契约的唯一家**：CLI 签名与退出码、输入分档、渲染义务、确定性口径、`manifest.json` 登记、调用位次与失败分档都写在这里。落点与封顶见 `workspace-guide.md` §6／§8 `R6`（本件不复述）；门禁档位与 W 组映射见 `review-rules.md` §6；决策见 ADR-0025。执行体＝`../../scripts/reader_html.py`（标准库、零网络、零第三方，唯一权威家在 skill 内）。

## 1 CLI 与退出码

```bash
uv run python .claude/skills/med-lit-review/scripts/reader_html.py --delivery workspace/YYYY-MM-DD-<slug> [--route P0|P1|P2|P3]
uv run python .claude/skills/med-lit-review/scripts/reader_html.py --delivery <目录> --check
```

| 项 | 口径 |
|---|---|
| 输出 | 交付根 `<slug>.html`（`<slug>`＝`manifest.topic.slug`；不含日期与 `-rN`）；同时登记 `agent/manifest.json` 的两段（§5） |
| 退出码 | `0` 产页（或 `--check` 一致）；`1` `--check` 不一致（页字节或登记漂移）；`2` 用法／输入／解析错误（含五类程序级失败，§6） |
| `--check` | 同盘复算比对＋对账，**不写盘**：一致打 `MATCH <sha256>`，不一致打 `MISMATCH` 并逐行给差异摘要 |
| `--route` | 覆盖路线判定；缺省按件存在性自动判（有八节包＝八节全页档；无八节包而有 `agent/scoping-note.md`＝P1 档；两者皆无＝退出 2 并报出实测 `agent/` 条目） |
| 读数 | 只走 stdout：输出路径与字节数、行／卡／节点／边计数、首屏三数（检索候选／本次研读／证据表；未取数记 `∅`）、`cap_hit`、正文自动成链计数、输入件指纹清单、登记结果 |

## 2 输入分档

**必需集（版内真源，缺即退出 2、不产页）**：`agent/knowledge-package.md`（八节正文＋§5 七列表 canonical）；`agent/cards/*.md`（目录缺或解析到 0 张即退出 2，文案含读取路径与解析条数）；`agent/reference-list.md`（行号↔DOI join 的版内真源；条数与 §5 行数不一致即退出 2，报出两处条数）；`agent/manifest.json`（`topic.slug`／`topic.dir`／`topic.delivered`／`caliber`）。P1 档必需集＝`agent/scoping-note.md` 与 `agent/manifest.json`。

**可降级集（`run/` 数据件，缺则通道降级、照常产页）**：被引数（`run/b1/cited-counts.json`／`openalex-enrich.json`）→ 列内与节点大小记 ∅；引文面（`run/b1/raw/citation-*.json`＋`citation-expansion.json`＋`step1-pools.json`＋`dedupe-report.json`＋`citation-graph.json`）→ 图位恒在、出降级块（§4）；可及性（`run/step5-accessibility.json`）→ 退回证据表「设计与等级」列状态词；高被引缺席核对（`run/b1/high-cited-check.json`）→ 区块缺席；研读选取读数（`run/b1/selection.json`）→ 首屏「本次研读」记 ∅（读者面「未取到」）。

**行号↔DOI 的 join 只走版内件**：`reference-list.md` 的行号即 §5 行号；DOI 归一（小写、去 `https://doi.org/` 前缀与尾标点）后连卡文件名（`agent/cards/<DOI-slug>.md`）。不依赖无生产者、未登记的 `run/` 中间件。

## 3 渲染义务

1. 页内身份头：**只有一行**，形如「交付 2026-09-19 ｜ 检索路线 完整路线 ｜ 渠道 灰色渠道默认启用」——通俗词在前，**身份码（交付目录 slug／路线码／渠道码）不进页首**，集中到页尾校验信息区（单文件外发自证）；页首不再有 eyebrow 一类的自我介绍行（ADR-0028）。
2. 答案先行：首屏＝研究问题＋§6.2 核心结论摘录（机器抽取，不手写）；正文次序按包内节序（新形态包为 §1→2→3→4→6→5→7→8）。摘录的节标题匹配与行引用匹配都按**本渲染器自己产出的两种写法**认（子标题带不带 `§` 前缀、行引用写「文献 N」还是契约记号 `行 N`）——匹配比产出更窄＝摘录静默为空；取不到即按程序级失败退出 2（§6 ⑤），不产只剩标签的空壳块。
3. 导航：sticky 顶栏锚点＋滚动高亮。锚点落点按**目标元素**算，不是按子标题算：`scroll-margin-top` 必须挂在导航的目标（`section`／`#s5`／`#row-N`／`#card-…`）上，且值取自 `--nav-h`／`--sticky-stack` 两个令牌（＝顶栏与紧固在它下面的筛选条的**实测**高度），不写死像素；两个令牌必须由脚本实测写回（`ResizeObserver` ＋ `resize`／`orientationchange` 兜底，字面常数只作首帧前的回退）——顶栏在 901–1075px 会折成两行（79px）、320px 折成四行（142px），写死一个值只是把自遮搬了个宽度；窄屏把筛选条改回随文滚动（它折行后 227px 会吃掉视口且自遮），锚点余量随之只算顶栏。深链落点自带 `:target` 标记，读者点开 `#row-N` 第一眼就能确认落对了。
4. 证据表：行卡形态＋筛选（主题／等级／全文获取／有无卡）＋排序（文献／被引数／等级）＋关键词搜索＋按主题分组；行锚 `#row-N`。搜索**必须把命中理由交出来**：命中藏在折叠的七列里时替读者展开该行，并把命中串标出来（`<mark>`）；命中标记每次筛选前先拆净，**拆完必须把被切开的文本节点并回一个（`normalize()`）**——不并，逐字输入会把节点逐次切开，跨接缝的词第二次起就再也标不出来（高亮只在第一次筛选时有效，而筛选计数照常正确，所以肉眼很难发现）；验收方式是按**真实键盘**逐字输入后断言「标记数＝命中行数」。零结果要有空态文案与「清除筛选」控件，命中数（`#visible-count`）是 `role="status"` 活动区——筛选是读者正在干活的动作，不做静默。行头三行互不重复：主行＝作者与题名（GB/T 单条引文就地拆档，不整条塞进主行）、副行＝年份·期刊·卷页（拆不出档位即整行不渲染——无条件渲染会留下孤立的「·」）、末行＝DOI 且**每行只出现一次**并成链（`https://doi.org/<doi>`；外链不是资源，不破 §3.10 自足）；完整引文只进七列「文献」列。
5. 提取卡：弹层抽屉为主（表行／图节点／卡片索引三入口）；前言字段按关键字段直出，`## 小节` 与其成员**整体折叠**（内容不省略；折叠标题列小节名与段名，无名段不显示段名、也不丢）；关闭三通道＝关闭钮 ✕／ESC／卡内返回链接；卡锚 `#card-<DOI-slug>`；焦点在关闭后复原到开卡元素。`aria-modal` 声明的「背后不可达」要真做到：开卡时把 `body` 下除弹层以外的元素**一律 inert**（含挂在 `body` 上的跳过链接——只点几个区块名会漏掉它），无 `inert` 的引擎退回 Tab 循环兜底；遮罩上滚轮不带走背后的页面。冷启动 `#card-…` 深链**直接开抽屉**——「稳定直达链接」不能落成一条折叠行。
6. 关系图：节点＝证据行 ∪ 有卡背景卡（主节点）＋相邻池内记录（次级节点）；边只有引文一种语义（实线＝后向、虚线＝前向，箭头恒指被引方）；大小＝被引数、色＝`§4` 主题、透明度＝**年份档**、描边＝可及性档位、形状＝有无卡；坐标＝预计算确定性纯函数；点有卡节点弹卡、无卡主节点跳证据行；键盘 Enter／Space 等价（SVG 须派发 `MouseEvent`）。
   **扇面布局（ADR-0030）**：主题扇区张角按 `Σ 点数×单点方格` 分配（主 3600＝60²、邻域 676＝26²），区内主带在内、邻域带紧接其外，**环带半径由点数与最小可视间距反推**；极坐标经 `x＝600＋554·ρ·cosθ`、`y＝450＋404·ρ·sinθ` 落到椭圆（可用区 1108×808、边距 46）。**带序（内→外）＝主带 → 邻域带 → 边走廊（88uu）→ 主题标签圈（30uu）**；半径按展开态一次定死，**折叠只换 viewBox、主节点坐标逐点相同**。单点方格是**面积账**（分角与可读性预算用）；铺开时的最紧圆心距由点径反解（主 50＝2×23＋4uu 命中圈余量、邻 22、跨带 35），比方格更紧，故预算恒在保守侧。
   **尺寸＝本包内相对被引数**（`r ∝ c^(1/3)`，本包 `min/max` 归一，正常档主节点直径 14–46、邻域 8–20——两层各自一把尺；走收缩梯时按梯缩小并把 `size_shrink` 落进数据块）；**跨包不可比**，图例必须写明。缺被引数单列「未取到」档（固定最小号＋空心问号描边，不进任何数值档），`c=0` 归最小档。线性映射与对数映射的对照、量程取舍见 ADR-0030 决定 5。
   **每个证据行主节点都带号**：圆内放得下就放圆内（字号 ≥11px），放不下按「上／右／下／左」固定次序外置避让——禁「放不下就静默不标」；**无表行的背景卡不编号**（读者面写「背景文献」，ADR-0028 义务 15）。落位框随数据块落盘，供门禁核「行号不压邻点」。
   **带取代个体跨主题弧**：**主-主跨主题引文一律按主题对聚成带**（带宽 ∝ √条数、带堆满走廊环、两端各打一枚主题色端点、带上标条数），个体引文降为读数；**只与背景点相连的跨主题边留在邻域层**（该层默认收起，展开才逐条出现）——默认视图里没有跨主题独立弧，这是 ADR-0030 决定 8「不画 151 条长弦」的落地边界。
   **邻域层＝背景层**：只收「至少有一条被画出的边」者（外弧带放不下就减邻域点数，**不压缩主节点**）；不承载主题色、不给 `data-*`／`tabindex`／`aria-label`／`<title>`、不给手型、不画命中圈，整层包在 `g[aria-hidden="true"]` 里；**默认收起**（ADR-0030 取代 ADR-0027 的默认展开），收起处原位写真实计数，折叠状态随打印走。只有主节点才有落点与键盘等价。
   **命中圈**：`≥ 点半径＋2uu`（整点可点）且 `≤ 最近邻距的一半`（命中区互吞会点错）；「最近邻」只按主节点算——背景点没有落点。
   **年份档＝四档绝对日历**（≤1999／2000–2009／2010–2019／≥2020，透明度 0.85／0.90／0.95／1.00，越老越淡；等量分位会把「年份」偷换成「本包最老的四分之一」，跨包不可比）；**缺年单列「年份未取到」档**（满透明度，不并入最新档——引文扩展池按「缺年当新文献」豁免，把未知画成「新」等于替它声称）；档定义随数据块落盘，**图例只画本包真有节点的档**。线性透明度不可取：27 个年份落进 0.45 的 alpha 区间＝每年 0.0167，实测压成 15 个值、档差约 0.03 对比度，通道本就不可辨（决策见 ADR-0027）。
   **填充色按合成值判**：年份档压在填充上，点色＝token 叠在 `--surface-soft` 之后的结果，所以 `--c1..--c-neutral` 必须在**最淡档**处仍 ≥3.0（实测各档 3.15–4.09）——只按 token 本身在画布上的观感调色不够；空心点（无卡的邻域）不承载主题色，其边界由描边负责。主题名在图上**只写名字、不带 `§` 号**（ADR-0028 义务 15）。
   图例＝**色样键**（`.legend .kp`／`.lg`／`.kl`／`.band` 一族，色值取在位 token）＋短标签，不写成一段散文——每条编码要在几十个圆点旁边逐条对照，写成散文等于要读者先背图例再看图；须写明「圆越大＝本包内被引越多（只在本包内可比、跨包不可比）」、「发表年份（越老越淡）」（保真度约束，防把「淡」读成「不重要」）、「数字＝文献号」、「粗带＝跨主题引用聚成的走廊」，并按实有取值派生形状键、圈线键与缺被引档键。
   图旁自述三句起：默认只画主节点与走廊带（相邻文献收放的真实计数写在按钮旁）、`cap_hit` 或预算裁点时的截断披露（上／候选计数与未上条数）、**孤点披露**（本次 K 个点没有连线、另有 M 个只以走廊带参与）——只进数据块不算披露：读者看图问的是「覆盖全了吗」。
   **墨水读数两条都判**：① 节点圆包围盒 ≥ 节点带（784×572，环心止于 286uu）的 85%——判「点铺满了自己的带」；② 节点 ∪ 带 ∪ 标签的全墨水包围盒 ≥ 可用区的 85%——判「图铺满了画布」。**可用区 85% 对节点圆本身不可达**：走廊 88uu ＋ 标签圈 30uu 按决定 3 占掉纵向 118uu，节点带的纵向半轴只有 286uu，故节点包围盒的天花板是 (2×286＋点径)/808＝76.5%；本包实测节点 90.3%×93.5%（占带）、全墨水 99.9%×94.2%（占可用区）。
   **两条执行纪律（2026-09-21 补；主节点偏少的包必踩）**：① `NODE_CAP` 是准入上限，不只在数据块里报出——邻域准入先按可读性预算取，再按「主节点永不截断」截到 `NODE_CAP − 主节点数`，被截部分单列读数 `dropped_node_cap`（与「外弧带放不下」的 `dropped_no_room` 分列，图旁自述句分别交代两种成因）。② 点数少于带容量时（邻域被上限截、或候选本来就少），按扇区把已放置的环心沿同一角度**按比例外推**至带外沿，使节点包围盒仍达带的 85%——只外推不内收，径向与角向间距只增不减，故「两点不相交／命中圈不互吞」不受影响；主节点 40 上下的包若不外推，实测节点包围盒仅 81.6%×86.2%，必踩本门。
   门禁改判**几何不变量**（W-07，取代「节点 ≤120／边 ≤250／`caps` 与常量全等」）：主节点数＝证据行＋背景卡数、任意两点不相交且行号不压邻点、所有点与标签在画布内、点径与被引数按口径可复算一致、扇区张角 ∝ 面积权重、走廊带数＝主题对数、两态取景＝同一批坐标、墨水铺满、截断与降级事实在场；旧常量 120／250 退为硬兜底。
7. 正文自动成链：「文献 N」→ `#row-N`（契约记号 `行 N` 与旧写法「证据行 N」都是它的子串，三种写法都认）、「§x.y」→ 节锚、卡 DOI → `#card-<slug>`；目标不存在即不成链（不制造悬空锚点）。
8. 可访问性：对比度 AA、`:focus-visible`、chips `aria-pressed`、弹层 `role="dialog"`＋`aria-modal`、跳过链接、`prefers-reduced-motion` 降级。AA 按**实际底色配对**判，不按 token 在画布上的观感：正文文字 ≥4.5 且要覆盖 `--surface-card` 与 `--surface-soft`（浅底上的链接与弱化文字用 `--accent-active`／`--muted`，承载白字的珊瑚底用 `--accent-strong`，`--accent` 只许落在深底上），图形与焦点圈 ≥3.0（关系图点填色对 `--surface-soft`、`--teal` 焦点圈对四种底色）。改任一个色值前按同一口径复算。
9. 打印：白底、隐导航／控制条／弹层／操作钮；`h2` 分页；行七列 `beforeprint` 全展、`afterprint` 还原；「打印含全部卡片」开关默认关。先读「其余层」同样 `beforeprint` 全展（`summary` 与折叠三角随 `screen-only` 退场），先读行的卡按钮也挂 `screen-only`——纸上没有可点的东西，印出一句「点某处」等于让归档件说谎。引用标记（文献号／等级／先读名次）**不得依赖背景图形**：导出 PDF 默认不印背景，深底反白会整块消失，而这些标记正是纸质归档里唯一还能引的锚——`@media print` 换成描边 chip（与 `.hero` 打印改白底同理）；章节号自链接在打印里去下划线。
10. 自足：无外链样式／脚本／字体／图片；断网 `file://` 直开、资源请求 0；长不可断词 `overflow-wrap: anywhere`。
11. 页脚＝**校验信息区**（页内唯一允许出现仓库路径、可粘贴命令与身份码的区域），标题「校验信息（交付件与命令）」＋原生 `<details class="review-fold">` **默认收起**：交付件清单（正文点名件＋关键四件，逐条「件名 · 路径」）、身份行（交付目录／路线码／渠道码）、复核命令（三件套＋页面复算，按在场件裁剪；引文面降级时附重跑命令）与输入件指纹 `path: sha256[:12]`（本次实际消费的输入件有序清单）。**打印时自动展开**（`beforeprint` 展开、`afterprint` 还原；打印面隐去折叠标题）；正文里指向本区的链接（`#review`）在点击与深链落点上先展开再落（ADR-0028）。
12. 先读三处呼应（§6 后独立列表／图上小圆牌／卡内小圆牌）是**条件件**：真源 `§5.1` 存在即渲染、缺席不留空壳（无卡路线不产该层）。三处同源＝同一份 §5.1 解析结果：先读区按真源块序渲染（散文照原渲染、先读层带名次、其后层按 `####` 主题分组并**默认收起**——行解剖与收容见义务 18；层标签句是形态标签，读者面由节首说明句与折叠 `summary` 承担），图上小圆牌只标先读层 `1..N`（`graph-data.nodes[].prio`），卡内小圆牌落在抽屉克隆的 `.card-body` 内并回链 `#priority`；`§5.1` 不在 §5 内二次渲染（渲染器先摘除该子段）。

13. 读者面文案（ADR-0028）：
    - **零内部词（第 5 轮补：判据面含「词」不只含「符号」）**：读者可见的一切文字只写临床读者不查本仓就能读懂的中文——`CONTEXT.md` 词条名、发现与交付流程用语、件名、脚本名、身份码、内部编号一律不进读者面；工具词与内部词（`schema`／`verbatim`／`abstract_source`／`证据表行号`／`页码指针` 一类）同样不进读者面——照录的来源内容（卡片正文、证据表引文列）不在此限，那是原文、不是我们的行文；写作规则见 `SKILL.md`「读者面文案（写作规则）」。门禁＝`check_delivery.py` W-21 两个判据面（符号面＋自写文本词面）。
    - **词表唯一家＝执行体**：`reader_html.py` 的 `ROW_LABEL`（文献）／`MISSING`（未取到）／`STATUS_VALUES`（有全文／仅摘要／仅题录）／`ROUTE_WORDS`／`CALIBER_WORDS`／`FILE_LABELS`（件名）／`POOL_FACE_WORDS`（图节点来源）／首屏三数标签与 hover 口径（`STAT_NOTES`：检索候选／本次研读／证据表）。契约记号 `行 N` 只进 markdown 真源、§5.1 表与锚点 id；缺失读数机器面记 `∅`；内部件路径／脚本名／可粘贴命令与身份码只进页尾校验信息区（正文里换成指向该区的件名链接）。
    - **身份与词分家**：锚点 id、DOI slug、文件名、数据块键名、卡片编号（`T14` 一类）是机器身份，不进读者面、也不改词；页面显示身份时一律换成读者身份（卡号→**文献 N**；无表行的背景卡→**背景文献**不编号）。
    - **零机器记号**：锚点记号、占位符与未渲染 markdown 记号一律不得出现——硬门禁 `W-21` 按此判定（`review-rules.md` §6）。

**实现取舍（已登记，非第二处口径）**：扇面坐标＝ADR-0030 决定 1／2 的具体实现——环带按「环容量＝弧长 ÷ 最紧圆心距、径向步长＝一个间距」铺开，点按名次由内向外摊（里满外散，把径向空间留给邻域带）；扇区容量按「主节点单方分角」这一最窄界算，故邻域准入是保守侧，不会出现「准入了却放不下」。可读性预算＝`π·286² ÷ 单点方格 − 主节点已占`（决定 4），超容量的容纳梯＝先减邻域点数、再按 `SIZE_SHRINK_STEPS` 收缩直径量程（主节点永不截断）。逐条线的入图次序按「两端名次的最大值」排，并**先给每个邻域点保底一条同类边**再补其余，故「邻域只收有边者」不靠事后补救。`graph_truncated` 的字段名沿用 03 票样图 `assets/03-sample-graph-payload.json` 的截断对象（`neighbourhood_candidates`＝03 §8 的 `candidates`、`kept_nodes`＝`kept`、`dropped_neighbourhood`＝`dropped_nodes`），另加 `dropped_no_room`／`dropped_no_edge`／`line_edges_*`／`band_edges`／`self_loops`／`size_shrink`／`band_only_kept`；被池内引用计数由渲染器从 `raw/` 种子引用表现场计数（与读法件同定义，但不受其 `--top` 截断；读法件只作 `seeds_with_refs` 的部分失败标注）。数据块另带 `layout`／`sectors`／`corridors`／`labels`／`frame`／`readings.ink` 六段几何读数，供门禁复算而不必借渲染器的实现。P1 构成图按四桶计数绘制（族×窗×来源读数留在 `run/b1/step1-diagnostics.json`，不重复画）。

14. 阅读路径与图例的派生规则（第 4 轮 critique 收口）：
    - **阅读顺序说明**：正文节序与序数不一致时（结论先于证据表，ADR-0008），在读者撞上它的那一刻（§6 节首）给一句说明与直达 §5 的跳链——序数保留规范编号，**不重编号**。
    - **同源说明**：同一批文献的另几处切法（先读／关系图／文献卡索引）各带同一句话（执行体常量 `SAME_SOURCE_NOTE`），指明主线在 §5 证据表。
    - **件名链接承诺目的地**：正文里的件名链接文案带 `DEST_HINT`（「（页尾校验信息）」），点击先展开该区再落位——只给件名不承诺目的地视同误导；同一段里只承诺一次（见义务 16）。
    - **同语义同交互**：主题徽章在证据表行与先读分组标题两处都成链（均指 `#s4-x` 节锚），不出现一处可点一处死。
    - **图例只画真有的取值**：形状键、圈线键、缺被引档键与走廊带键按本交付实际存在的取值派生（与 ADR-0027 的年份档同一口径），另设「数字＝文献号（圆内放不下时在圆旁）」键解释图上的行号标签。
    - **窄屏不缩字号**：≤900px 时关系图容器横向可滚、SVG `min-width: 900px` 并出一行滑动提示；打印时容器 `overflow: visible`——把 9.5px 的字缩成 5.6px 等于把图变成噪点。

15. 第 5 轮 critique 收口（与 13／14 同属读者面口径）：
    - **名与号分工**：主题在读者面**必须有名字**（chip／行徽章／分组标题），**号不得单独出现**——
      它可以与名字同现（筛选 chip 与先读分组标题写「§4.1 指南与共识」），也可以只留在 `href` 与
      悬停提示里（证据行徽章只写主题名）；表单控件与按钮不得只给机器码（裸 `§4.2`／`E1`／`有卡`），
      缩写要给全称（`有文献卡`）。
    - **定义与控件同屏**：等级（E1–E5）与全文获取三值的定义放在筛选条下方；表尾只留指针，
      不留唯一解释（首次用筛选的人必须先读到判据，才能按键）。
    - **链接落到它点名的那一件**：件名链接的 `href` 是 `#file-<件名>`，页尾按同一函数出锚点；
      一律落到附录顶部＝没承诺目的地。
    - **按钮名承诺真实结构**：行内展开按钮写「展开全部字段」（展开的是纵向字段块，不是七列）。
    - **计数单位跟读者词走**：证据表计数写「篇」（与每行自称「文献 N」一致），不写「行」。

16. 第 6 轮 critique 收口（交互、打印与一致性）：
    - **筛选后把筛选条带回粘性位**：结果收缩会把粘性筛选条推出视口（读者失去计数与筛选态），
      状态变化后逐次检查、只补差额把它带回粘性线（不做整节跳转）。
    - **打印白名单**：打印件只保留正文装置，屏上 affordance 挂 `screen-only` 类退场（换页、勾选框、
      折叠三角、图上操作件都在此列）；判据＝纸上不出现任何「只能点／只能滑／只能勾」的东西。
    - **卡片索引 chip 是真链接**：`<a class="card-chip" href="#card-<slug>">`＋`data-open-card`
      渐进增强（右键可复制、新标签可打开）；索引不重复「文献 N」。
    - **同一个东西在页上只有一个名字**：卡内字段名按执行体词表映射到证据行七格词表
      （`标识`→文献、`设计与E级`→设计与等级、`干预/暴露`→干预与暴露、`结局/效应量`→结局与效应量、
      `偏倚与升降级`→偏倚备注、`与本文关系`→与结论的关联）；卡是真源，词表唯一家＝执行体。
    - **关系图的四件小事**：主题标签最后绘制并带纸色衬底（先画会被圆点压印）；命中圈按最近邻距
      自适应（邻点比命中半径近时点圆心会误触别人的卡）；折叠相邻层后 viewBox 复排到主节点包围盒；
      节点 `aria-label` 只给短名单（题名｜文献 N｜年｜档｜被引），长详情留给 `<title>`。
    - **焦点与落点**：抽屉的 Tab 环不管引擎有无 `inert` 都闭合；跳过链接的落点（`#main`）
      与各节一样带顶栏高的 `scroll-margin-top`。
    - **首屏数字与导航**：三个数字＝**检索候选**（`run/b1/dedupe-report.json` 的 `final_count`）／
      **本次研读**（`run/b1/selection.json` 的 `selected_total`）／**证据表**（表行数）——三数是一条递进
      关系（检索候选 → 本次研读 → 证据表），每枚数字的 hover 口径都写清它在链上的位置；前两枚是可降级
      读数，缺件或该键不存在一律记 ∅、读者面写「未取到」（不伪造、不为旧包保留旧标签分支、缺件不崩），
      版内三件与三数的对账口径见 ADR-0032 §8；「下载队列」「文献卡」两枚数字退场。`toc` 里先读区标出
      「（§5.1）」；先读「其余层」分组标题写「其余篇目 ·」并按主题号排序（与「按 §4 主题分组」的宣称一致），
      分组标题与它的名单同处一个折叠（默认收起、打印展开，见义务 18）。
    - **件名提示同段只出一次**（修订义务 14 的逐链接要求）：同一段里第一个件名链接承诺目的地
      「（页尾校验信息）」，其后同段的件名链接不再重复——重复 30 次会把承诺变成噪声。

17. 第 7 轮 critique 收口（卡片呈现：卡头、身份块、段序与等级释义）：
    - **卡头三段式**：题名一行、「作者 等 年份」一行、徽章一行（等级／被引／全文获取）；
      卡头不重复「文献 N」（返回链、索引副行与证据行仍带编号）；8 张背景卡徽章行留一枚
      「背景文献（未列入证据表）」。题名取**卡内身份段第 3 段的源题名**（60/60 可派生，
      且比证据行「文献」列完整——行里的单条引文常缺副题）；作者年份由身份段派生，
      **卡首行解析只作兜底**且必须剥掉内部卡号前缀与「（全文状态…）」括注；抽屉头与卡头同源
      （题名作可访问名，作者年份与徽章各一行），不另造一套标题。
    - **索引 chip**：主行＝题名（先按标点语义截断、否则按词边界截断，一律补省略号），
      副行＝`文献 N · 作者 年份 · 等级`；被引降为悬停提示；60/60 张不得出现残句或内部卡号。
    - **身份块逐行**：题名／作者／来源（期刊与年卷页）／DOI 四行 ＋「其他标识与附注」
      （PMID、注册号、资助、许可、日期、「本轮读到：PDF p.x–y」）；切分按位置（位分隔符只在**括注外**
      算分隔符——括注里的竖线是字段内容），运行时校验 **年份位**（四位数年份开头）与
      **DOI 位**（DOI 值与带 `DOI` 记号的两种写法都收），任一不成立即**整段回退原样**
      ——不拿猜测的分段误导读者。段名表（题名／作者／来源／DOI／其他标识与附注）的唯一家仍是执行体。
      **回退不静默**：逐行张数与回退名单（件名＋成因）随渲染读数进 stdout 与
      `derived.reader_html.counts`，交付侧由门禁 `W-23` 与页面块数、卡件数三方对账（`review-rules.md` §6）。
    - **固定读者序与按名直出集**：「文献→研究要素→设计与等级→人群→干预与暴露→结局与效应量
      →与结论的关联」为默认直出序，折叠区同序（偏倚备注→未见未知→可引用摘录→作者自认局限→
      未登记段保文档序殿后）；**直出判定按段名，字段与 `##` 小节一视同仁**，段序只对顶层段生效、
      小节成员跟随其小节；缺席不留空壳。**卡文文字零改写**（决策见 ADR-0029）。
    - **标签剥离按括号深度扫描**：`名称（括注）：正文` 里的括注允许内套括号（`研究要素（人群 …；对应研究问题：…ARNI（sacubitril/valsartan）…）：P＝…`）；
      按深度归零且紧随冒号才切。研究要素的括注**摘出而不丢**——「对应研究问题：…」单列段内首行，
      P/I/C/O 名称对照降为段名旁小注；小节名与字段名同规（括注降为小注，名字不飘）。
    - **等级释义同交互**：全页唯一一份释义（五档含义＋话术四句：先验≠最终档、一档内升降与三类降档理由、
      封顶托底、不升降档≠未评估；**不提偏倚评价工具名**）；悬停任一处等级记号均可出，
      **键盘每卡一枚入口**（落在「设计与等级」段名旁），卡文里的记号不逐枚给 tab 停靠点；
      覆盖抽屉、证据表行内徽章与七列文字、索引副行、**先读行副行**、筛选 chip 与定义句；ESC 先收释义再关抽屉；
      抽屉关闭时一并收释义；释义弹层不随抽屉 inert；`prefers-reduced-motion` 下无过渡。
      档位含义只写协议与实测能支撑的，**不为 E4／E5 补先验映射**。
    - **打印不依赖悬停**：筛选条下的定义处展开成完整含义表一次（`beforeprint` 展开、`afterprint` 还原），
      释义弹层随 `screen-only` 退场。
    - **图节点读屏名**：落实义务 6 的短名单（题名｜文献 N｜年｜状态｜被引）——题名取自卡内身份段，
      整条引文与 DOI 一类长详情全部留 `<title>`。
    - **卡模板同步**：身份段的位置约定（作者｜年｜题名｜来源｜DOI｜附注）写进 `reading-card-template.md`，
      后续交付不再依赖运行时猜测。

18. 第 8 轮 critique 收口（先读区的行解剖与收容，决策见 ADR-0031）：
    - **先读行＝三行块**：① 名次圆牌（仅先读层，写「先读 N」，与卡内徽章同词）＋**题名**
      （本行唯一指向 `#row-N` 的链）＋行尾「打开文献卡」；② 副行＝`文献 N · 年份 · 等级 · 全文获取`
      ＋维度；③ 理由。题名取**卡内身份段的源题名**（与卡头、图节点读屏名同源），**整条呈现**——
      不截断、不砍副题，长题名折行（先读行是「认文献」的主场；单行截断的旧口径见 ADR-0031 窄修订）。
      索引 chip 才用单行截断（`chip_title()`，56 字，见义务 17）。
      **行内不得出现第二个通向同一目标的链**——重复的链接不是冗余装饰，是让读者以为有两件事可看。
    - **理由末尾的出处指针指向本行时不重复显示**：编号与状态词已在同一行的副行里出现，句尾再挂一次
      就是同一行说三遍。真源形态与 `W-06` 判据不变（它读的是 markdown）；指向**别行**的指针保留成链，
      那不是重复，是跨行引用。
    - **其余层默认收起**：这一节标题问「先读哪几篇」而内容含全部篇目，实为全量名单；先读层常显、
      其余层收进一个原生 `<details>`（`summary` 写「其余 N 篇 · 按主题分 G 组」），组标题与计数仍在。
      打印自动展开、`summary` 与折叠三角随 `screen-only` 退场；该折叠区内不含任何别处的链接目标，
      故不存在「深链落进折叠行」。
    - **维度三词当场定义**：`结论关联`／`权衡价值`／`主题补位` 是理由的分类，读者不查到判据就按键＝
      让他在三个陌生词里猜。定义写节首常驻一行（纸面同文），不靠悬停（纸上没有悬停）。

## 4 确定性口径

**承诺**：输入件字节不变 ⇒ 重跑渲染逐字节相同；`--check` 即该承诺的执行体（真实 topic 的 manifest 命令是完整性钉子，`run/` 依赖网络重取、不承诺跨跑字节复原）。实现纪律：

- 无时间戳、无随机、无 `uuid`、无 locale 依赖格式化（耗时只进 stdout，页内不出现生成时刻）。
- 遍历一律显式排序（卡按文件名、表行按行号、图节点按 03 定序含 DOI 破并列），不依赖文件系统返回序。
- 浮点定点：坐标 1 位、半径／透明度 2 位；内联 JSON 固定键序与分隔符，`<` 转义防 `</script>` 提前收块。
- **`agent/manifest.json` 不进输入指纹与 `inputs[]`**：渲染器自登记会改其字节，纳入即自指（`--check` 恒不一致）；页内身份取自 `topic`／`caliber`，不改字节。

## 5 `manifest.json` 登记

- `versioned_artifacts[]` 增/换 `{path: "<slug>.html", sha256}`（根件不带前缀；紧随 `INDEX.md` 项写入）。
- `derived.reader_html = {path, sha256, inputs[{path, sha256}], command, counts, machine_reads: false}`：`inputs` 只列本次实际消费的件（有序、全量 sha256，漂移比对键）；`command` 为仓库根工作目录下的复算命令；`counts`＝身份段逐行覆盖读数（`cards`／`ident_rows`／`ident_fallback[{card, reason}]`，由门禁 `W-23` 与页面块数、卡件数对账；回退是保真口径、但不许静默）；`machine_reads: false`（内容真源仍是 markdown，机器断言从 HTML 自身解析）。P1 档（无卡域）不写 `counts`。
- 登记是**幂等**的：语义无变化即零写（不触盘、不改字节）。`regeneration[]` 不收 HTML 项（该段语义＝`run/` 被忽略件）。
- 擦除演练：`run/` 重建后核 `derived.reader_html.inputs[].sha256`——全等即跑 `--check`；任一不符（网络漂移）记「输入漂移、跳过字节比对」，不判失败（`workspace-guide.md` §6／§15）。
