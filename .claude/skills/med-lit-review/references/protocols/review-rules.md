# 校验规则与词表（确定性事后检查的人读说明）

本文件说明 `scripts/review_knowledge.py` 的规则子集、级别、报告契约与词表。可执行唯一定义处是脚本本身，两处不一致以脚本为准；词表只查确定性子集，语义判断一律交人工。

<!-- 注：只查确定性规则，不判说服力 / 逻辑连贯 / 引用准确性（后者交人工 + 方法论）。S 类语体与“总结句概念堆砌”两条已弃（噪音大、属逻辑连贯），交研读完整性硬规则 R4 人工看。 -->

## 1 用法与退出码

```bash
uv run python scripts/review_knowledge.py <包.md> \
  [--format text|json] [--cur-year YYYY] [--rules R1-01,R1-03,...] [--lexicon 词表路径] \
  [--cache-dir 缓存目录] [--no-cache]
```

- 纯本地文本检查：不读密钥、登录票据、代理凭证、机构信息，不发网络请求；报告只含行号 / 规则 / 上下文。
- `--cur-year` 默认取系统当前年；端到端与回归必须固定传入（可复现）。
- `--rules` 默认全 15 条；只接受规则 id，未知 id 走用法错误。
- `--lexicon` 默认指 `references/lexicon/term-lexicon.yaml`（T-01 真源）；文件缺失或不可解析时按无表处理（T-01 不报）并在 text 模式标明，不判用法错误。
- `--cache-dir` / `--no-cache`：词表解析缓存（缺省＝skill 包内 `.cache/lexicon/`，键＝词表文件 `sha256` ＋ 解析器版本，与 `term_expand.py` 共用同一格）。命中同样过结构校验，损坏格按 miss 重解析；表缺失不查缓存、回退语义不变（缓存不让错表入场）。留痕：stderr 一行 `CACHE lexicon source=cache|parse|off …`，端到端门禁把它记进 `assertion-results.json` 的 notes。
- text 模式第一行打「词表：<版本或无表>」，供报告引用版本号；json 契约不变。零 finding 时只打「词表：…」与「小结：error=0 warning=0 info=0」两行（无逐行行，也不打印「无 finding」以外的占位）。
- 退出码：`0` = 无 error；`1` = 有 error；`2` = 用法或文件错误（文件不存在 / 非 UTF-8 / 未知规则）。warning 与 info 不阻断。

| 级别 | 含义 | 处置（门映射见 05 号票资产 §4） |
|---|---|---|
| error | 结构或可追溯的硬事实被破坏 | 硬门禁：R1-03 / ST-01 / L-03 清零 |
| warning | 需人工复核痕迹或进局限声明 | 复核痕迹（F-02 / F-04 / L-08 / R3-01 / T-01 同义）或清零（R1-01 占位） |
| info | 提示级，不阻断 | 人工过目即可（F-03、T-01 易混） |

脚本内级别不等于交付硬门槛：门映射由 05 号票定，本文件与脚本都不改门禁。

## 2 报告契约

人读行（text）：

```text
{file}:{line} [{rule}/{severity}] {message} | 上下文：{context} | 建议：{suggestion}
小结：error={e} warning={w} info={i}
```

机器契约（json，`ensure_ascii=False, indent=2`）：

```json
{
  "file": "<输入文件 basename>",
  "summary": { "error": 0, "warning": 0, "info": 0 },
  "findings": [
    { "line": 13, "rule": "R1-03", "severity": "error",
      "message": "…", "context": "…", "suggestion": "…" }
  ]
}
```

- 五字段 = 行号 / 规则 / 问题 / 上下文 / 建议，另加 `severity` 构成 findings 的六个键；字段名保持英文，内容全中文。
- `file` 只记 basename（可复现、不写本地路径）；findings 按 行号 → 规则表顺序 → 消息 排序。

## 4 词表（可执行副本在脚本内，此处为规则清单）

- 八节要素同义：执行摘要（执行概要 / 摘要 / 概要）、研究问题（括号内文字不参与匹配）、检索策略（检索方案 / 检索方法）、主题式证据综合（主题式综合 / 主题综合 / 证据综合）、证据表（证据汇总）、结论、方法附录（方法学附录 / 附录）、局限声明（局限与未知 / 局限）。
- 研究问题陈述（ST-02 判据）：§2 内有问句（含「？」）或有「研究问题：／系统化研究问题：」标签行即算在；旧形态（要素条目、PICO 挤写）不再兼容，历史内容已离线迁移。
- 模糊引用词表：多项研究表明、多项研究显示、有研究表明、有研究显示、大量研究表明、若干研究表明、研究表明、研究显示、某研究、专家认为、专家表示、普遍认为、一般认为。
- 待补占位：`[待补充出处]`、`[待查证]`（`未见原文` 是内容标记，不进占位判定；可及性状态见 `SKILL.md` R5）。
- 绝对词表：证明、证实、治愈、根治、首选、金标准、彻底、必然、毫无风险、绝对安全、完全消除、彻底证明、彻底证实。
- 强措辞表：显著 +（降低 / 下降 / 减少 / 改善 / 提高 / 获益 / 优于 / 延长）；明确 +（降低 / 下降 / 减少 / 改善 / 提高 / 获益 / 优于 / 支持）；证实、证明、确证（“确证性”设计标签除外）。否定用法（无 / 未 / 不 / 非 紧邻）不报。
- 术语词表（真源在 `references/lexicon/term-lexicon.yaml`；四分语义与消费见 `references/protocols/term-lexicon-protocol.md`，此处只列本脚本可执行口径）：
  - 同义（报 warning）：家族内出现两个及以上中文形即报（`MI` 等英文与缩写保留不判）；家族由 YAML `synonym_sets` 声明。
  - 易混（报 info）：词表 `confusable` 边两词同篇并现即报；互不为子串才算并现（`心梗` 落在 `心肌梗死` 之外，故两者并现才能触发）。
  - 上下位（不报）：`AMI ⊂ MI`、`心梗 ⊃ STEMI / NSTEMI` 这类边并现不判混用。
  - 正字变体（静默归一不报）：`心肌梗塞 ≈ 心肌梗死`；`SGLT2 ≈ SGLT-2`。
  - 无表姿态（宁漏勿噪）：表缺失／不可解析即 T-01 不报——不给任何内置关系（`--lexicon` 指向不存在的文件即走此路）。
- GB/T 7714 类型标识：`[J]/[M]/[D]/[C]/[R]/[S]/[P]/[N]/[G]/[Z]/[DB]/[CD]/[EB/OL]/[J/OL]/[M/OL]/[C/OL]/[DB/OL]`。

## 5 边界与已知近似

- 只查确定性规则，不判说服力 / 逻辑连贯 / 引用准确性；L-03 为确定性近似（识别无引用标记的陈述句，豁免过渡与方法与局限类句子），R3-01 / L-08 只做词表交叉提示。
- 认节只匹配标题正文、括号内文字不参与（“### 5.1 增量列表（可复现审计摘要）”不算摘要节）；节号只认 1–99 的起首数字，为避免误报不看年份起首标题。
- 断言类规则（R3-01 / L-03 / L-08）只扫断言区散文（执行摘要 / 主题式证据综合 / 结论）：证据表行是证据本体、方法节与局限节非断言，均不扫；L-03／L-08 另排除 §6.1–6.3 子区间（6.4 仍扫，条目必须带行号）。
- M-01 只看 6.1／6.3 子区间散文：任一 `\d` 即报；小节标题行（`### 6.1`／`### 6.3` 本身）不计，代码块整段跳过。
- M-02 只看 6.2 子区间散文：提取效应量类数字（含 `%`、小数、`HR／RR／OR／CI／I²` 附近数值、`n=` 后数值）；每个须在证据层（§4／§5／6.4／引文表全文）出现，否则报；豁免形态为四位年份（19xx／20xx）与字母紧邻的标识符数字（如 MK-0616、EU/1/15/1034、SJ20202002）。
- M-03 只认 §6 内四块小标题（`6.1 背景`／`6.2 核心结论`／`6.3 讨论`／`6.4 支持结论`，允许同义措辞）；缺任一即报；§6 整节缺失时由 ST-01 报，此处不重复。
- L-09 只判「带状态词的行是否在 §8 按行号出现」：状态词只看证据表「设计与等级」列（标注漂到别列即漏判，由人工复核），§8 侧只认 `行 x` 形式指针；不判措辞强弱与交代是否充分（语义判断归 R4）。仅题录出表后（ADR-0023）本规则实际只对 `仅摘要` 行生效——仅题录不占表行，其 §8 交代由验收门禁 `E-06` 按 DOI 核，其「不得摘要可得」由 `E-19`（硬门禁）核：凡标 `仅题录` 者不得在可及性清单 `abstract_source`、落点报告「摘要」列或库内 `abstractNote` 上取到摘要，核心交叉核对离线可算。
- R1-03 豁免页码区间（`卷(期):起页-止页`），避免把页码四位数字读成未来年份；写成“2027-2030 年”这类年份区间的表述若落在该形态内会被跳过，交人工看。
- F-02 只看类型标识缺失 / 错配，不判著录全量格式（全量交人工逐条核对，沿 09 号票引文分工）。
- T-01 只查中文混用；英文与缩写保留不报错，正字变体静默归一。
- ST-02 只判 §2 里有没有研究问题陈述（问句或「研究问题：」标签行二者其一即算在）；不判问题质量与措辞。历史包与归档件按注记处理，命中 ST-02 属预期，不追溯迁移。
- 表行不判模糊引用与断言类问题；代码块整段跳过；行内代码与 URL 先剥离再判。

## 6 门映射与及格线

脚本 verdict 是读数，交付门禁是更窄的一层判据，两者不混：error 不等于一律阻断，warning 也不等于无不干系。

### 硬门禁七项

脚本报 error 的规则中七条为**交付硬门禁**，任一未过即不算交付：

| 硬门禁 | 规则 id | 含义 |
|---|---|---|
| 未来年份 | R1-03 | 引文／断言出现晚于 `--cur-year` 的年份 |
| 缺八节要素 | ST-01 | 八节任一缺失（可同义措辞） |
| 断言后无证据表行 | L-03 | 断言区散文句未点到证据表行 |
| §6 四块要素不全 | M-03 | 缺 6.1／6.2／6.3／6.4 任一小标题 |
| 6.1／6.3 出现数字 | M-01 | 背景与讨论段散文含数字 |
| 6.2 数字在证据层查不到 | M-02 | 核心结论段效应量数字无法在证据层回查 |
| 仅摘要行未进局限声明 | L-09 | 带 `仅摘要` 状态词的行未在 §8 逐行交代（仅题录已不占表行，改由验收门禁 E-06／E-19 按 DOI 核） |

其余 warning 走人工复核痕迹或进局限声明（T-01 同义混用、R1-01 占位清零或已进局限）。


交付硬门禁之外，验收门禁另有一条涉可及性的硬门禁：**仅题录须可证无摘要（E-19，ADR-0023）**——凡标 `仅题录` 者不得在可及性清单 `abstract_source`、落点报告「摘要」列或库内 `abstractNote` 上取到摘要，任一取到即判不过；核心交叉核对离线可算，`--no-live` 只跳过库内加强项。

结构／封顶类停在软项读数是本形态既定边界（内容／契约类可进交付门禁）；该边界与三件套扩面的决策记录见 ADR-0025 与 ADR-0010 窄修订条，提档须先解禁。每条硬断言配孪生场景自证：`uv run python scripts/check_delivery.py --selftest`（改过本执行体或解析模块后必跑）。

另两条 W 门不在本执行体：**W-13 版内件零机密**与验收门 G-06 是同一条门的两处消费——`evals/acceptance/run_gate.py` 的 `secret_scan` 纳入 `.html`，扫描前剥离样式／脚本块、内联数据 URI 与 CSS `url(...)`（外链面另由 W-02 守）。W-01..W-08 与 W-20 随 04／05 号票挂进本执行体，W-12 随 03 号票，W-22 随 ADR-0032，W-23 随 ADR-0033（身份段逐行覆盖）。

### 及格线

**可追溯全过，其余缺口全部写入局限声明即过。** 分工：生成时的行为禁令不在此处，见 `SKILL.md`「研读完整性硬规则」；本节只做事后确定性检查，两边不重复。

### 快线豁免

- P2／P3：六门全守（缺席节保留标题＋一句跳步声明即齐 ST-01）。
- P1：产 scoping-note，**不跑** `review_knowledge.py`（该脚本对象是八节包，不是豁免）；P1 的校验门另行约定。
