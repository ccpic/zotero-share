# 落点规则（placement-guide，医学实例化）

本文件只定医学落点实例化。词汇见根 `CONTEXT.md`；通用做法（放置闭环、维度规则、全文链、校验）见 `use-zotero` 内 `references/placement.md`；决策见 ADR-0002（批量确认）、ADR-0007（挂载）。与上游不一致时以上游为准。

## 1 闭环

走 `use-zotero` 放置闭环（候选二至四个、首个为推荐位、`--dry-run` 计划表、一次确认、逐条回查 + 计数校验）。本 skill 单篇不例外（交互点三）；有人值守用户缺席留未分类记断点；AFK 按交互点三回退全自动建挂（ADR-0013）；任一段可显式跳过，记断点不记失败。本次合集（`CONTEXT.md`）为多归类并存的一挂：集名沿交付目录名原文 ASCII slug，父级固定 `med-lit-review`，只增不删，同名复用；P2／P3 不建集。落点报告带摘要列与摘要计数行（取数与清洗口径见 ADR-0021；列与计数行格式见 references/templates/placement-report-template.md，本文件不复述）；摘要缺口非阻断（未填与不适用不进失败）。**写库范围（ADR-0032）**：＝研读选取集 − 仅题录成员（＝有卡集）——可及性为「有全文」或「仅摘要」的选取成员才建条目，仅题录成员一律不建条目、不入库，只在可及性清单与知识包 §8 逐条交代（DOI）；落点计划条目集 ≡ `agent/cards/*.md` 的 DOI 集（硬门禁 W-22，卡与计划均在包内、离线可算）。

## 2 医学落点表

| 编号 | 文献情形 | 落点 |
|---|---|---|
| 1 | 指南与共识 | 进指南目录，不放药品目录（指南分流） |
| 2 | 多药荟萃与类比较（含网状荟萃分析） | 进机制父级，不猜单药（荟萃分流） |
| 3 | 单药各期试验（I/II/III 期）与单药系统综述 | 进药品目录；III 期可与 III 期目录嵌套，优先已存在架构 |
| 4 | 观察性/真实世界（前瞻队列、登记库、横断面、用药模式、依从性、达标率、流行病学） | 进疾病目录为主，按干预/药品兼挂第二落点（多归类并存）；E 级（E2/E3）只备注不影响落点 |
| 5 | 监管文件（说明书/审评/产品特征概要） | 有监管子集进子集，无则暂落药品目录本身，禁擅自新建 |

| 7 | 命中现有收藏集语义（程序） | 只定推荐位；经 skill 链路一律一次确认后写库，不静默写；有人值守用户缺席留未分类；AFK 全自动建挂；人工日常单篇才沿静默放置（批量链路确认优先） |
| 8 | 无合适目录或跨类歧义（程序） | 问用户，不新建（本次合集除外：经交互点三确认或 AFK 特批即非擅自新建） |

其余类型归属：联用方案进疾病目录、按成分多挂；亚组/特殊人群按主题落点兼挂，不单列；安全性专篇按比较范围定（单药→药品目录、多药→机制父级、跨类→疾病目录 + 多挂）；机制/基因/PK-PD/剂量建模进机制父级兼挂疾病；叙述综述/病例报告/会议摘要落点家不变，研读约束仍归 R3 与 R5（综述只进背景、病例仅安全性行、会议摘要禁支撑结论、可及性三档待遇见 R5）。以上语义落点之外，每行另多一挂本次合集（`placements` 数组追加本次合集 key；既有条目原收藏集不动、只追加本次合集）。

## 3 边界

通用边界见上游：无合适目录或跨类歧义问用户不新建、监管子集缺席暂落药品目录本身（词汇见 `CONTEXT.md`）；在库只认 DOI 字段、标题关键词 + `qmode=everything` 比对、片段式标识符零命中不得直接建条目（做法见 `use-zotero` 内 `local-api.md` 写入前去重）。

## 4 附件挂载口径（医学实例化）

载体（本 skill 特有）：挂载清单取研读选取集＝本任务 Step3 下载台账（行集＝`agent/download-queue.txt` 条目；列取实际来源报告＋身份核验）；挂载面＝写库范围（研读选取集 − 仅题录成员，无附件条目不进本清单）。其余走上游：直挂／补漏环／既有条目默认补挂／附件回查做法见 `use-zotero` 全文链，决策见 ADR-0007，口径见 `CONTEXT.md` 正文附件。落点报告附件列、摘要列与计数行格式见本 skill `references/templates/placement-report-template.md`（摘要取数链路见 ADR-0021）。

## 5 机密不记

密钥、登录票据、代理凭证、机构信息四样不复述、不记资产。报告只写渠道类名（免费、仓储、机构授权路线），不写具体机构名。
